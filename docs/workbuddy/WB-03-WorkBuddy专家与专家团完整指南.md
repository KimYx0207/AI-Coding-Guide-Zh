## 开始之前：先理解三个层次

老金先帮你把概念层次理清，不然后面会乱：

```text
直接对话   = 你跟通用 AI 聊，啥都能问，啥都不精
专家       = 召唤一个有职业身份的 AI 角色（比如财务专家），专业但不贵
专家团     = 召唤一组专家分工协作，团长自动拆解并行干，最强但最贵
```

**消耗关系**：直接对话 < 单专家 < 专家团（专家团通常是单专家的 3-5 倍）

**选用原则**：能直接对话就别用专家，能用单专家就别用专家团。**别动不动上专家团烧积分**。

准备清单：

```text
✅ WB-02 装好登进去了，跑通过最小任务
✅ 当前账号有积分（看一下余额，至少够跑 3-5 个专家任务）
✅ 一份非敏感的真实素材（旧的周报、公开资料、会议纪要都行）
```

## 第一步：从专家中心挑对专家（15 分钟）

### 1.1 进入专家中心

主界面左侧栏找**专家**或**专家中心**入口（不同版本叫法可能不同，认准"专家"二字）。点进去，你会看到按行业或岗位分类的专家列表。

WorkBuddy 内置上百位专家，覆盖主流办公场景，老金挑常见的几类给你认认：

```text
- 写作类：办公写作、文案撰写、公文写作、新媒体运营
- 分析类：数据分析、市场调研、财务分析、竞品分析
- 文档类：会议纪要、周报月报、PPT 制作、简历优化
- 设计类：UI 设计、海报设计、LOGO 设计
- 技术类：编程专家、产品经理、测试工程师
- 法律类：合同审查、法律咨询（注意：仅供参考，不替代律师）
```

### 1.2 怎么挑（看卡片三栏）

每位专家都有一张卡片，点开能看到三栏信息，老金教你按这个顺序读：

```text
1. "擅长领域"：先看这个，确认它干的活是不是你要的
2. "能力介绍"：看它具体能做什么、不能做什么
3. "任务示例"：抄它的提问方式（这是官方给你的"最佳提问模板"）
```

> 💡 **挑专家的核心原则**：**贴任务，不贴名气**。别一看"院士级专家"就点，要看它的擅长领域对不对得上你要干的活。写周报就找办公写作专家，别找战略咨询专家。

### 1.3 第一次实战：让数据分析师帮你看表格

老金带你跑一个比 WB-01 更进阶的任务。准备好一份非敏感的表格（比如一份旧的销售记录、一份公开的市场数据），然后在专家中心找"数据分析"或"表格分析"类专家，点**召唤**。

进入对话后，把表格文件拖进去（或按 App 提示上传），然后发这段：

```text
这是一份 [说明这是什么数据，比如"上季度各产品线销售记录"]。

帮我做三件事：
1. 找出数据里最异常的 2-3 个点（突增、突降、明显偏离均值）
2. 用一段话总结整体趋势
3. 给我 3 条可以行动的建议（不要空话，要具体到"做什么"）

不要修改原数据。分析结果用 Markdown 表格 + 文字说明。
```

### 1.4 你会看到什么

```text
- AI 用专业分析师的视角回复（提到异常值、趋势线、对比基准等专业框架）
- 产出包含：异常点表格、趋势总结、3 条可执行建议
- 如果数据有缺失或乱码，它会先问你确认
```

### 1.5 卡住了怎么办

```text
❌ 找不到合适的专家
   → 用专家中心的搜索功能（通常在顶部），输入你的任务关键词
   → 或换种描述搜（"分析表格"不行就搜"看数据""做报表"）

❌ 专家回复太浅，没专业感
   → 检查是不是选错了专家类型（比如该找"财务分析"却找了"通用分析"）
   → 在提问里加更多专业约束（比如"按杜邦分析法拆解""用漏斗模型分析"）

❌ 上传的表格它读不了
   → 检查格式（Excel、CSV 通常都支持，复杂合并单元格可能读不全）
   → 把数据简化后再传，或先转成 CSV

❌ 回复特别慢
   → 单专家一般 10-60 秒，超过 2 分钟可能卡了，取消重试
   → 复杂分析任务可以接受稍长一点
```

## 第二步：怎么提问让专家发挥最好（关键技巧）

老金这一步讲的是**提问技巧**——同样一个专家，提问方式不同，产出质量天差地别。这是真正决定你能不能把 WorkBuddy 用好的核心能力。

### 2.1 黄金提问模板

老金给你一个通用模板，把方括号填好，专家就能发挥八九成。

> 💡 **懒人简版**（嫌长的，记住这五要素就够）：**身份 + 任务 + 输入 + 输出格式 + 边界**。哪怕只写这五行，也比"帮我写个周报"强 10 倍。

```text
【角色确认】
你现在是 [专家的具体身份，比如"资深销售数据分析师"]。

【任务背景】
我需要 [你要解决的事，比如"给领导汇报上季度销售情况"]。
背景信息：[补充一两句，比如"公司是做 SaaS 的，Q3 刚做了大促"]。

【输入材料】
[上传文件，或粘贴数据、文档内容]

【具体要求】
1. [第一件要做的事，越具体越好]
2. [第二件要做的事]
3. [第三件要做的事]

【输出格式】
用 [Markdown 表格 / Word 文档结构 / PPT 分页大纲] 呈现。
语气：[专业 / 通俗 / 给领导看 / 给客户看]。
字数或篇幅：[控制在 X 字 / X 页 / X 分钟读完]。

【边界约束】
不要 [明确不能做什么，比如"不要修改原数据""不要编造没给的数字"]。
如果信息不够，先问我。
```

### 2.2 三种典型问法对比

老金用同一个"写周报"任务，给你看提问好坏的差别：

**❌ 笼统问法**（专家发挥不出来）：
```text
帮我写个周报。
```

**⚠️ 中等问法**（能用但不出彩）：
```text
我是运营，帮我写一份这周的周报，要专业一点。
```

**✅ 黄金问法**（专家全力发挥）：
```text
你现在是资深运营专家。
我需要给部门 leader 汇报本周工作，目标是体现进度 + 暴露风险。
背景：电商运营，本周做了三场活动，GMV 涨了 12% 但退货率也涨了。
本周事项：
1. 双品日活动上线，GMV 80 万
2. 处理上周末的客诉集中爆发
3. 跟设计对下周主推款的视觉

请按"本周进展 - 数据亮点 - 风险与协调 - 下周计划"四段结构出周报。
语气专业但不啰嗦，800 字以内。如果某些数据我没给，先用占位符标出来让我补。
```

### 2.3 老金总结的提问五原则

```text
1. 身份先确认：开头明确专家身份，强化它的角色意识
2. 任务有目标：不是"帮我写"，而是"为了 X 目标写"
3. 输入要具体：给数据、给背景、给约束，别让对方猜
4. 输出有格式：明确结构、字数、语气，产出直接能用
5. 边界要划清：什么不能做、什么先问，避免跑偏
```

记住这五条，你用任何 AI 工具（不止 WorkBuddy）都能比别人产出高一截。

## 第三步：专家团——多角色协同干复杂活（20 分钟）

### 3.1 什么时候该升级到专家团

老金先帮你判断什么任务值得用专家团（别浪费积分）：

```text
✅ 值得用专家团：
   - 复杂任务，单一岗位干不完（竞品分析要市场+财务+产品三方视角）
   - 一次出多种成果（Word 报告 + Excel 数据 + PPT 汇报）
   - 重要任务，值得花 3-5 倍积分换端到端交付
   - 跨领域整合（一个产品方案要技术+设计+运营+法务一起想）

🚫 不该用专家团：
   - 单一专业就能干完（写封邮件、做个表、改段文字）
   - 第一次试用（先单专家跑熟）
   - 积分紧张（专家团很快烧光）
   - 简单粗暴的执行类任务（不需要多角色思考）
```

### 3.2 第一次专家团实战：做一份竞品分析

老金带你跑一个典型专家团场景——**做竞品分析**。准备一个你熟悉的产品（自家产品或公开产品都行），到专家中心切到**专家团**分类，找"竞品分析"或"市场调研"类的专家团卡片，点**召唤**。

进入对话后，发这段：

```text
我是 [你的公司/岗位]，需要做一份 [自家产品/某竞品] 的竞品分析。

请分析这几个竞品：[列出 2-3 个竞品名称]
分析目的：[给领导决策产品方向 / 给销售打单用 / 自己研究市场]

请输出一份完整报告，包含：
1. 各竞品的产品定位和核心卖点
2. 功能对比矩阵（表格形式）
3. 价格和商业模式对比
4. 各自的优劣势（SWOT 简化版）
5. 给我家的 3 条差异化建议

格式：Word 报告结构，专业但不晦涩，3000 字以内。
如果某些公开信息查不到，先标注"待补充"，不要编造。
```

### 3.3 你会看到什么

发出去后，**等的时间会比较长**（专家团要拆解、并行、合并，通常 2-5 分钟）。期间你可以看到进度（哪些专家在干哪一块）。

最终产出：

```text
- 一份完整报告，包含你要求的 5 个部分
- 功能对比是真正的表格（不是文字描述）
- 每个部分都带"由 XX 专家负责"的标识（你能看出分工）
- 结尾有团长（项目经理 AI）的整合说明
```

### 3.4 专家团卡住了怎么办

```text
❌ 跑到一半失败 / 提示积分不足
   → 专家团消耗大，先查余额。免费额度通常不够跑一次完整专家团
   → 缩小任务范围（比如竞品从 5 个砍到 2 个）再试

❌ 产出拼凑感强，各部分脱节
   → 任务描述要更明确"整合要求"，比如"最后要有一段统一结论"
   → 换个更对口的专家团卡片

❌ 跑得太久（超过 10 分钟）
   → 任务可能太大，取消后拆成 2-3 个子任务分别跑
   → 或退一步用单专家分阶段做（虽然要手动接力，但更可控）
```

## 第四步：自建专属专家团（广场没有的就自己造）

### 4.1 为什么要自建

WorkBuddy 广场上的专家团是通用型的，但你可能有特别垂直的需求——比如"只服务我们家律师事务所的合同审查团""只做跨境电商内容创作的团"。这时候用自建专属专家团，把你的业务上下文固化进去。

### 4.2 怎么建（用引导对话）

WorkBuddy 提供交互式引导，你不用写代码，跟它对话就行：

```text
第一步：在专家中心找"创建专家"或"我的专家"入口
        （两个都找不到？去设置或帮助里搜"创建"，或看你本机版本是否支持自建）
第二步：跟引导说你的需求，比如：
  "我想组建一个做内容创作的专家团，成员要有：
   - 标题党文案专家（负责吸睛标题）
   - 长文写作专家（负责深度内容）
   - 配图建议专家（负责视觉规划）
   - 排版优化专家（负责阅读体验）"
第三步：WorkBuddy 会帮你生成每位专家的人设、方法论
第四步：你审一遍，觉得不对的让它改
第五步：保存，下次直接召唤你这个专属团
```

### 4.3 自建的注意事项

```text
✅ 专家数量别贪多：3-5 个角色最合适，再多协调成本高
✅ 每个专家边界要清：明确谁干啥，避免产出重复
✅ 团长要会拆任务：自建团的重点是把"怎么分工"讲清楚
✅ 沉淀业务知识：把你们公司的术语、模板、过往案例放进专家的"经验"里
❌ 别指望一次建好：自建团要反复跑、调整，迭代 3-5 次才顺手
```

### 4.4 分享和复用

建好的专属专家团通常可以**分享给同事**（生成分享码或链接）。团队里一个人建好，其他人导入就能用，避免重复造轮子。具体分享机制看你本机 App 当前版本支持的方式。

## 第五步：高级技巧和老金的私房建议

### 5.1 专家的"组合拳"

有时候一个任务需要多个专家接力，但又不值得上专家团。老金的玩法是**手动组合**：

```text
场景：做一份产品发布 PPT
1. 先找"市场调研专家"出市场背景（5 分钟）
2. 再找"产品专家"基于调研写产品卖点（5 分钟）
3. 再找"设计专家"把卖点转成 PPT 大纲（5 分钟）
4. 最后找"文案专家"润色每页文字（5 分钟）

总耗时 20 分钟，比专家团慢但消耗只有专家团的 1/3，且每步你都能微调。
```

### 5.2 给专家喂你的"风格样本"

想让专家产出贴合你个人/公司风格，最好的办法是**喂样本**：

```text
提问时附加：
"参考这三份我之前写的周报风格 [上传 3 份样本]，
按这个语气和结构来写。"
```

专家会学到你的行文习惯、用词偏好、段落节奏，产出从"通用 AI 味"变成"你自己的味"。

### 5.3 专家不是万能的——什么活别交给它

```text
🚫 需要最终判断的决策（签不签合同、发不发公告、投不投钱）
   → 专家能准备草稿和分析，最终决定必须人来做
🚫 涉及客户隐私、未公开财务的敏感任务
   → 别轻易上传，先用脱敏素材试
🚫 完全没标准答案的开放创造（起公司名、写品牌主张）
   → 专家能给方向，但灵魂要你自己注入
🚫 实时变化的信息（股价、新闻、库存）
   → 专家的知识有截止时间，实时数据要靠连接器（看 WB-05）
```

## 常见问题

**Q1：专家和直接对话到底差多少？**
差别在"角色化"。直接对话像跟一个什么都会的实习生聊，专家像跟一个有具体职业身份的人聊。复杂任务、专业场景，专家产出明显更贴。但简单任务（写个通知、回答常识）差别不大，别浪费专家的积分。

**Q2：专家团的 3-5 倍消耗值得吗？**
看你任务的价值。如果一次专家团出一份你本来要花 2 小时自己做的报告，那很值；如果只是写封邮件，那亏大了。判断标准：**任务值不值得花你 1 小时以上？值得就用专家团，不值得就用单专家或对话**。

**Q3：自建专家团要花多长时间？**
第一次建通常 30-60 分钟（说需求、调人设、试跑）。建好之后能反复用，长期收益高。建议从最常做的那类任务开始建。

**Q4：专家回复我听不懂，太专业了怎么办？**
在提问里加一句"请用大白话解释，假设我是 [你的角色，比如非技术同事]"。专家会自动调档，把专业内容翻译成你能懂的。

**Q5：能让专家记住我的偏好吗？**
可以。WorkBuddy 通常有"我的偏好"或"专家记忆"设置，把你常用的格式、语气、术语存进去。具体入口看你本机版本。另外自建专家时可以把偏好直接写进人设。

**Q6：专家会替换掉我们团队的人吗？**
不会替换，但会改变分工。专家擅长"整理、分析、生成、初稿"，最终判断、客户沟通、创意决策还是要人。用好专家的团队，每个人能管更多事，但不是裁员工具。

**Q7：专家团跑失败了扣的积分退吗？**
通常不退。所以第一次用专家团前，先用单专家把任务边界摸清，再上专家团。免费额度别拿来试专家团。
