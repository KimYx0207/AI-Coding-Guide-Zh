老金写这篇教程的目的——让你学会 WorkBuddy 最核心的玩法：**召唤专家**和**组专家团**。WB-01 你已经召唤过一个专家写过周报，这篇带你把这个能力彻底用透，包括怎么挑专家、怎么进入行业 Buddy 的专属工作台、怎么提问、什么时候升级到专家团，以及怎么自建专属专家团。

学完这篇，你就能像管一个 AI 团队一样使唤 WorkBuddy。

## 开始之前：先理解三个层次

老金先帮你把概念层次理清，不然后面会乱：

```text
直接对话   = 描述目标与素材，让通用 AI 完成任务
专家       = 召唤一个有职业身份的 AI 角色（比如财务专家），按岗位方法处理任务
专家团     = 召唤一组专家分工协作，由团长拆解任务并协调各角色
```

**消耗怎么看**：按「订阅和用量」中的实际记录评估。任务复杂度、模型和处理量都会影响消耗，不能仅凭用了几个专家就推算固定倍数。

**选用原则**：先用能完成任务的简单方式；需要专门方法时选单专家，需要多角色分工时再用专家团。试跑后再判断额外协作是否值得。

准备清单：

```text
✅ WB-02 装好登进去了，跑通过最小任务
✅ 当前账号有积分（看一下余额，至少够跑 3-5 个专家任务）
✅ 一份非敏感的真实素材（旧的周报、公开资料、会议纪要都行）
```

## 第一步：从专家中心挑对专家（15 分钟）

### 1.1 进入专家中心

在左侧栏进入**专家·技能·连接器 → 专家**。没有看到时先检查“更多”，再按 WB-01 的排障步骤核对自定义菜单和当前应用范围。进入后浏览与你的任务有关的专家卡片。

WorkBuddy 内置上百位专家，覆盖主流办公场景，老金挑常见的几类给你认认：

```text
- 写作类：办公写作、文案撰写、公文写作、新媒体运营
- 分析类：数据分析、市场调研、财务分析、竞品分析
- 文档类：会议纪要、周报月报、PPT 制作、简历优化
- 设计类：UI 设计、海报设计、LOGO 设计
- 技术类：编程专家、产品经理、测试工程师
- 法律类：合同审查、法律咨询（注意：仅供参考，不替代律师）
```

### 1.2 怎么挑（看卡片三栏）

每位专家都有一张卡片，点开能看到三栏信息，老金教你按这个顺序读：

```text
1. "擅长领域"：先看这个，确认它干的活是不是你要的
2. "能力介绍"：看它具体能做什么、不能做什么
3. "任务示例"：抄它的提问方式（这是官方给你的"最佳提问模板"）
```

> 💡 **挑专家的核心原则**：**贴任务，不贴名气**。别一看"院士级专家"就点，要看它的擅长领域对不对得上你要干的活。写周报就找办公写作专家，别找战略咨询专家。

### 1.3 第一次实战：让数据分析师帮你看表格

这次用 7 行虚构订单。里面有重复记录、缺失金额、真实的 0 元订单和全额退款，先把这些处理对，再看图表。去专家中心选择适合数据分析的专家，将 [orders.csv](../../examples/office-lab/orders.csv) 拖入对话，或把下面的内容保存为 UTF-8 编码的 `orders.csv`：

```csv
订单ID,渠道,实收金额,退款金额,日期
A101,网站,120,0,2026-09-07
A102,网站,200,20,2026-09-07
A102,网站,200,20,2026-09-07
B201,门店,80,0,2026-09-08
B202,门店,,0,2026-09-08
C301,网站,0,0,2026-09-08
D401,门店,150,150,2026-09-09
```

没有表格软件也可以直接粘贴这段 CSV。然后发送：

```text
请处理这份虚构订单数据，原文件保持不变。
1. 同一订单ID且全部字段相同，只计一次；同ID内容冲突则单列待确认。
2. 实收金额为空的记录单列待确认，不参与订单数和金额汇总；真实的 0 要保留。
3. 按渠道汇总有效订单数、实收金额、退款金额和净收入。净收入=实收金额-退款金额。
4. 先给处理明细和汇总表，写出使用的计算方式，再生成两渠道净收入柱状图。
这里只能判断这批订单的净收入，不能推断利润、增长率或退款原因。
```

### 1.4 你会看到什么

先对照处理过程：重复的 A102 少计一行；B202 缺少实收金额，留在待确认表；C301 的 0 元有效，D401 全额退款也仍是一笔有效订单。最终参与汇总的是 5 笔。

| 渠道 | 有效订单数 | 实收金额 | 退款金额 | 净收入 |
|---|---:|---:|---:|---:|
| 网站 | 3 | 320 | 20 | 300 |
| 门店 | 2 | 230 | 150 | 80 |
| 合计 | 5 | 550 | 170 | 380 |

如果合计不是 380，先逐行找去重、空值或退款处理的问题。可以具体反馈：“C301 的 0 是真实金额，请保留；B202 的空值不能自动填 0。”不要先让它换一张更漂亮的图。

数字核对后，要求把结果保存为新文件：一张汇总表、一张待确认明细表，并保留原始 CSV。打开结果文件，检查中文列名、金额和图表标签；柱状图的两个净收入值应为 300 和 80。官方的 [数据分析与可视化实战](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Practice-Cases/Practice-Three) 说明了文件导入、统计维度和图表输出的操作方式。

自己再试一轮：只把 B201 的退款金额改成 10，另存一份样例，不抄上面的提示词重新提任务。此时门店净收入应为 70，合计为 370，订单数仍为 5。

### 1.5 卡住了怎么办

```text
❌ 找不到合适的专家
   → 用专家中心的搜索功能（通常在顶部），输入你的任务关键词
   → 或换种描述搜（"分析表格"不行就搜"看数据""做报表"）

❌ 回复有很多专业名词，却没有处理明细
   → 要求列出重复、缺失和保留的记录，再给汇总公式
   → 先检查结果能不能对应到原始行，再决定是否换专家

❌ 上传的表格它读不了
   → 检查格式（Excel、CSV 通常都支持，复杂合并单元格可能读不全）
   → 把数据简化后再传，或先转成 CSV

❌ 回复特别慢
   → 看任务是否仍在读取文件或计算；先用这 7 行样例缩小问题
   → 中断前保存已有结果，说明卡在哪一步，避免反复发起同一任务
```

### 1.6 行业 Buddy 跟练：在专属工作台做一份经营摘要

行业 Buddy 把某个企业或行业的工作模式、专家、技能和连接器放进一个专属工作台。它会影响你能选到什么能力，也会影响任务可以在哪里继续。先用一份小数据练习，不急着接入公司的业务系统。

**进入前准备**：使用你有权访问的 Buddy 应用，准备下面这份虚构数据。本例只需要文本分析，不需要邮箱、网盘或企业数据库。

#### 第一步：选应用，确认授权范围

1. 点击 WorkBuddy 首页**左上角的应用入口**，查看应用名称、简介和提供方，再进入与你的报表或经营分析任务相符的应用。各账号看到的列表可能不同，没有指定行业应用时，不要照着教程猜一个名字。
2. 首次进入会出现应用授权框，可能包含读取任务列表、任务详情等信息。确认提供方和读取范围符合你的用途后再授权；不能接受就返回通用版。
3. 部分应用还会要求绑定第三方账号。本例优先**跳过**这一步；若选中的场景必须依赖该账号，换一个只处理所给材料的场景。需要真实业务数据时，再单独处理对应授权。

看不到应用入口或目标应用，可能是账号尚未获开放。此时可以先用前面的单专家练习熟悉同一份数据，但这不等于已经使用了行业 Buddy。

#### 第二步：选工作模式和场景

进入后，首页会换成该应用的新建任务界面：

- 首页的大胶囊用于选择**工作模式**，决定这次会话的业务角色与工具组合。
- 输入框上方的**场景胶囊**对应预置任务，选中后可以召唤绑定的专家，并展示预设指令卡片。
- 输入框中的专家、技能、连接器列表与当前应用的配置有关。切回通用版后，不能假定这些专属能力仍然存在。

选择与“经营摘要”“报表分析”接近的模式或场景。若没有对应场景，使用该应用允许的普通任务入口，自己描述目标；不要求它拥有教程中没有核实过的固定按钮。

#### 第三步：发送一个不依赖外部数据的任务

把下面的完整材料粘贴进输入框：

```text
请根据以下虚构门店数据写一份经营摘要，只使用我提供的信息。

门店,订单数,销售额,退款额
甲店,20,2400,120
乙店,15,1950,50

请输出：
1. 每家门店的净销售额，计算式为销售额减退款额。
2. 两家门店合计订单数、销售额、退款额、净销售额。
3. 两条值得继续调查的问题，明确写成待验证问题。

用一张 Markdown 表格和不超过 200 字的说明回答。
不要查询外部系统，不要推断利润或增长率，不要发送、发布或修改原始数据。
如果当前场景要求连接外部账号，先说明需要什么数据，不要自行授权。
```

#### 第四步：核对结果，再决定是否复用

先核对数字，角色口吻是否专业放在后面：

| 项目 | 甲店 | 乙店 | 合计 |
|---|---:|---:|---:|
| 订单数 | 20 | 15 | 35 |
| 销售额 | 2400 | 1950 | 4350 |
| 退款额 | 120 | 50 | 170 |
| 净销售额 | 2280 | 1900 | 4180 |

材料没有上期数据和成本，所以不能给出“增长了多少”“哪家利润更高”等结论。若出现这类内容，把缺少依据的句子指出来，让它仅保留算式与待调查问题。数字正确后，再让它按你的周报格式改写；仍然只使用这份材料。

#### 第五步：继续原任务，处理应用边界

在当前应用里打开刚才的任务，追加“把摘要改成三条周报要点”。若切回通用版后任务能看到、输入框却置灰，并提示只能在某个 Buddy 应用中使用，就切回提示中的来源应用继续。这是应用的使用范围限制，不代表会话丢失。

不再使用某个应用时，可到**设置 → 应用管理**查看已授权的第三方应用与 Buddy 应用，并撤销授权。这个入口在 5.6.0 加入；旧版若只显示“Buddy 应用”，可先按该页面的实际操作管理授权。撤销授权后，已经发给第三方的数据仍需按对方的数据管理规则处理。

| 卡住的位置 | 先检查什么 |
|---|---|
| 看不到目标应用 | 当前账号是否已获开放；先完成通用专家练习，不反复重装 |
| 场景一直要求绑定账号 | 任务是否依赖外部数据；本例换成只读所给文本的场景 |
| 找不到通用版中的专家或技能 | 当前应用是否提供该能力，不能把两边列表当成同一份 |
| 结果数字不对 | 把“销售额减退款额”的算式与具体错误指出来，要求重新计算 |
| 换应用后无法继续输入 | 根据提示回到来源应用；保留已有结果，不删除任务重来 |

## 第二步：怎么提问让专家发挥最好（关键技巧）

老金这一步讲的是**提问技巧**——同样一个专家，提问方式不同，产出质量天差地别。这是真正决定你能不能把 WorkBuddy 用好的核心能力。

### 2.1 黄金提问模板

把已经跑通的任务整理成模板，下次只替换材料和具体问题。

> **简版**：身份、任务、输入、输出格式和边界。先说明要做什么、依据什么、怎样判断结果，再按需要补充细节。

```text
【角色确认】
你现在是 [专家的具体身份，比如"资深销售数据分析师"]。

【任务背景】
我需要 [你要解决的事，比如"给领导汇报上季度销售情况"]。
背景信息：[补充一两句，比如"公司是做 SaaS 的，Q3 刚做了大促"]。

【输入材料】
[上传文件，或粘贴数据、文档内容]

【具体要求】
1. [第一件要做的事，越具体越好]
2. [第二件要做的事]
3. [第三件要做的事]

【输出格式】
用 [Markdown 表格 / Word 文档结构 / PPT 分页大纲] 呈现。
语气：[专业 / 通俗 / 给领导看 / 给客户看]。
字数或篇幅：[控制在 X 字 / X 页 / X 分钟读完]。

【边界约束】
不要 [明确不能做什么，比如"不要修改原数据""不要编造没给的数字"]。
如果信息不够，先问我。
```

### 2.2 三种典型问法对比

老金用同一个"写周报"任务，给你看提问好坏的差别：

**❌ 笼统问法**（专家发挥不出来）：
```text
帮我写个周报。
```

**⚠️ 中等问法**（能用但不出彩）：
```text
我是运营，帮我写一份这周的周报，要专业一点。
```

**✅ 黄金问法**（把材料和要求说清楚）：

下面的活动与 GMV 数字都是虚构的，只用来展示描述任务的方法。

```text
你现在是资深运营专家。
我需要给部门 leader 汇报本周工作，目标是体现进度 + 暴露风险。
背景：电商运营，本周做了三场活动，GMV 涨了 12% 但退货率也涨了。
本周事项：
1. 双品日活动上线，GMV 80 万
2. 处理上周末的客诉集中爆发
3. 跟设计对下周主推款的视觉

请按"本周进展 - 数据亮点 - 风险与协调 - 下周计划"四段结构出周报。
语气专业但不啰嗦，800 字以内。如果某些数据我没给，先用占位符标出来让我补。
```

### 2.3 老金总结的提问五原则

```text
1. 身份先确认：开头明确专家身份，强化它的角色意识
2. 任务有目标：不是"帮我写"，而是"为了 X 目标写"
3. 输入要具体：给数据、给背景、给约束，别让对方猜
4. 输出有格式：明确结构、字数、语气，产出直接能用
5. 边界要划清：什么不能做、什么先问，避免跑偏
```

记住这五条，你用任何 AI 工具（不止 WorkBuddy）都能比别人产出高一截。

## 第三步：专家团——多角色协同干复杂活（20 分钟）

### 3.1 什么时候该升级到专家团

老金先帮你判断什么任务值得用专家团（别浪费积分）：

```text
✅ 值得用专家团：
   - 复杂任务，单一岗位干不完（竞品分析要市场+财务+产品三方视角）
   - 一次出多种成果（Word 报告 + Excel 数据 + PPT 汇报）
   - 重要任务，需要多个角色协作，且能接受试跑后的实际积分消耗
   - 跨领域整合（一个产品方案要技术+设计+运营+法务一起想）

🚫 不该用专家团：
   - 单一专业就能干完（写封邮件、做个表、改段文字）
   - 第一次试用（先单专家跑熟）
   - 积分紧张（专家团很快烧光）
   - 简单粗暴的执行类任务（不需要多角色思考）
```

### 3.2 第一次专家团实战：做一份竞品分析

老金带你跑一个典型专家团场景——**做竞品分析**。准备一个你熟悉的产品（自家产品或公开产品都行），到专家中心切到**专家团**分类，找"竞品分析"或"市场调研"类的专家团卡片，点**召唤**。

进入对话后，发这段：

```text
我是 [你的公司/岗位]，需要做一份 [自家产品/某竞品] 的竞品分析。

请分析这几个竞品：[列出 2-3 个竞品名称]
分析目的：[给领导决策产品方向 / 给销售打单用 / 自己研究市场]

请输出一份完整报告，包含：
1. 各竞品的产品定位和核心卖点
2. 功能对比矩阵（表格形式）
3. 价格和商业模式对比
4. 各自的优劣势（SWOT 简化版）
5. 给我家的 3 条差异化建议

格式：Word 报告结构，专业但不晦涩，3000 字以内。
如果某些公开信息查不到，先标注"待补充"，不要编造。
```

### 3.3 你会看到什么

发送后，观察当前任务显示的分工与执行进度，先确认是否仍在查资料或等待工具。耗时、角色署名和最终展示方式以本次任务实际结果为准。

检查报告是否覆盖你要求的五项，功能对比是否清楚，价格和功能信息能否打开来源核对，各角色的结论是否在整合时遗漏或互相冲突。不要把看到了多个角色当成已经完成交付。

### 3.4 专家团卡住了怎么办

```text
❌ 跑到一半失败 / 提示积分不足
   → 查看该次任务的实际用量和余额；缩小材料与分工范围，不按“免费额度必定不够”决定是否付费
   → 缩小任务范围（比如竞品从 5 个砍到 2 个）再试

❌ 产出拼凑感强，各部分脱节
   → 任务描述要更明确"整合要求"，比如"最后要有一段统一结论"
   → 换个更对口的专家团卡片

❌ 跑得太久（超过 10 分钟）
   → 任务可能太大，取消后拆成 2-3 个子任务分别跑
   → 或退一步用单专家分阶段做（虽然要手动接力，但更可控）
```

## 第四步：自建专属专家团（广场没有的就自己造）

### 4.1 为什么要自建

WorkBuddy 广场上的专家团是通用型的，但你可能有特别垂直的需求——比如"只服务我们家律师事务所的合同审查团""只做跨境电商内容创作的团"。这时候用自建专属专家团，把你的业务上下文固化进去。

### 4.2 怎么建（用引导对话）

先在当前专家或专家团页面查是否提供自定义创建入口；没有时，不用去设置里猜“创建”按钮，也不把草拟的团队说明当成已保存的专家团。

可以先让 AI 帮你写一份角色配置草稿：内容创作任务由标题、长文、配图与排版角色分工，明确输入材料、输出和团长整合要求。若当前账号提供创建与保存流程，再把草稿填入该入口，逐项审阅并用小任务验证。创建能力与入口按 [官方专家说明](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Expert-Center) 和本机实际页面确认；本次该说明页未取到正文，不保证所有账号均可完成自建。

### 4.3 自建的注意事项

```text
✅ 专家数量别贪多：先从少量角色开始，用实际分工和整合结果判断是否需要增加
✅ 每个专家边界要清：明确谁干啥，避免产出重复
✅ 团长要会拆任务：自建团的重点是把"怎么分工"讲清楚
✅ 整理业务材料：把允许使用的术语、模板和案例放进任务引用或当前创建流程提供的配置项，不把“经验”当成固定可点按钮
❌ 别指望一次建好：自建团要反复跑、调整，迭代 3-5 次才顺手
```

### 4.4 分享和复用

专家链接直达已经有官方更新记录，但不能据此推断所有自建专家团都提供分享码、链接或导入功能。先检查已保存对象实际提供的分享操作；没有入口时，可以把角色配置草稿交给同事，由对方在自己的账号按可用流程配置。外部账号和资料权限需要各自核对。

## 第五步：高级技巧和老金的私房建议

### 5.1 专家的"组合拳"

有时候一个任务需要多个专家接力，但又不值得上专家团。老金的玩法是**手动组合**：

```text
场景：做一份产品发布 PPT
1. 先找"市场调研专家"出市场背景（5 分钟）
2. 再找"产品专家"基于调研写产品卖点（5 分钟）
3. 再找"设计专家"把卖点转成 PPT 大纲（5 分钟）
4. 最后找"文案专家"润色每页文字（5 分钟）

上面各步的时间只是练习安排；实际耗时与积分以任务记录为准。手动接力的好处是每步都能检查和调整，不保证固定的省时或省积分比例。
```

### 5.2 给专家喂你的"风格样本"

需要围绕某条已有回复追问时，5.6.0 起支持把选中的会话消息引用到输入框。先选中要讨论的消息，用引用入口带入，再补充“请根据这段结论修改第三项”；发送前核对引用内容，避免把旧结论当成新增材料。

想让专家产出贴合你个人/公司风格，最好的办法是**喂样本**：

```text
提问时附加：
"参考这三份我之前写的周报风格 [上传 3 份样本]，
按这个语气和结构来写。"
```

专家会学到你的行文习惯、用词偏好、段落节奏，产出从"通用 AI 味"变成"你自己的味"。

### 5.3 专家不是万能的——什么活别交给它

```text
🚫 需要最终判断的决策（签不签合同、发不发公告、投不投钱）
   → 专家能准备草稿和分析，最终决定必须人来做
🚫 涉及客户隐私、未公开财务的敏感任务
   → 别轻易上传，先用脱敏素材试
🚫 完全没标准答案的开放创造（起公司名、写品牌主张）
   → 专家能给方向，但灵魂要你自己注入
🚫 实时变化的信息（股价、新闻、库存）
   → 明确要求使用可用的网页搜索技能或已授权连接器，并核对来源和查询时间；不能只凭专家名称当作实时数据
```

## 常见问题

**Q1：专家和直接对话到底差多少？**
专家提供特定角色的方法与工具，直接对话也可以清楚描述任务。用同一份小材料比较处理明细、事实准确性和实际用量，再决定哪种方式适合，不因专家名称就保证效果更好或固定多扣积分。

**Q2：什么任务值得用专家团？**
看任务是否需要多角色分工，以及试跑后的成果和积分消耗。先用一份小素材试一次，再按交付质量、节省的时间和实际消耗决定是否扩大任务；简单邮件、短通知等任务通常不需要专家团。

**Q3：自建专家团要花多长时间？**
第一次建通常 30-60 分钟（说需求、调人设、试跑）。建好之后能反复用，长期收益高。建议从最常做的那类任务开始建。

**Q4：专家回复我听不懂，太专业了怎么办？**
在提问里加一句"请用大白话解释，假设我是 [你的角色，比如非技术同事]"。专家会自动调档，把专业内容翻译成你能懂的。

**Q5：能让专家记住我的偏好吗？**
先把常用格式、语气和术语写进本次任务要求。需要长期保存时，按当前客户端可见的记忆设置或自定义专家说明操作；不把“我的偏好”“专家记忆”当成固定按钮，也要用新任务验证这些要求是否实际生效。

**Q6：专家会替换掉我们团队的人吗？**
不会替换，但会改变分工。专家擅长"整理、分析、生成、初稿"，最终判断、客户沟通、创意决策还是要人。用好专家的团队，每个人能管更多事，但不是裁员工具。

**Q7：专家团跑失败了扣的积分退吗？**
先查看该次任务的用量记录和当前退款规则。失败不代表一定没有消耗，也不能据此承诺自动退回积分；第一次先缩小任务范围，再决定是否继续。
