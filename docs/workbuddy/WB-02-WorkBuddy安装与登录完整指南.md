## 开始之前：先确认你的环境

老金把环境清单放最前面，免得你装到一半才发现卡住：

```text
✅ 操作系统：Windows 10/11 或 macOS（苹果芯片或 Intel 都行）
✅ 硬盘空间：留 1-2 GB 给 App 和缓存
✅ 内存：8 GB 以上更稳（4 GB 也能跑，慢一点）
✅ 网络：能正常上网的办公或家庭网络（国内直连，不用翻墙）
✅ 一个微信账号（个人微信或企业微信都行，用来扫码登录）
✅ 管理员权限（Windows 装软件、Mac 拖到 Applications 都需要）
```

> 💡 **企业内网用户先看这条**：如果你在公司电脑装，公司有严格的安全软件（比如 360 企业版、火绒企业版、深信服终端管理），装之前先问 IT 这几件事——允许不允许装、要不要加白名单、有没有代理设置。很多"装不上"的坑不是 WorkBuddy 的问题，是企业内网拦截。

## 第一步：下载安装包

### 1.1 去哪下载

打开浏览器（Edge、Chrome、百度、必应都行），搜"WorkBuddy 腾讯"或"WorkBuddy 官网"。

> ⚠️ **认准官网**：搜索结果里点**带"官方"标识**或**网址里带 tencent / workbuddy 字样**的链接。别点带"广告"字样的（那些是推广位，可能跳到不相干的站点）。WorkBuddy 是腾讯出品，官网一定在腾讯域名下。

进入官网后，找**下载**或**免费下载**按钮（通常在首页显眼位置）。官网会自动识别你的系统（Windows 还是 Mac），给你对应的安装包。

> 💡 **要不要先注册账号？** 不用。下载、安装都不需要账号，你只要装完打开 App、用微信扫码登录那一刻才需要账号。微信就是你未来的账号。

### 1.2 选对版本

如果官网给了多个版本，老金告诉你怎么选：

```text
- Windows 用户：选 .exe 安装包（不选 .msi 的便携版，新手用安装包更稳）
- Mac 用户：看清芯片类型
   - 苹果芯片（M1/M2/M3/M4）：选 ARM 版或 Apple Silicon 版
   - Intel 芯片（老 Mac）：选 Intel 版或 x64 版
   - 不确定自己 Mac 是什么芯片？点左上角苹果图标 → "关于本机" → 看"芯片"那一栏
```

> 💡 **Mac 用户防坑**：下完 .dmg 文件后，双击打开，把 WorkBuddy 图标**拖进 Applications 文件夹**（别直接双击运行，会丢权限）。第一次启动如果提示"无法验证开发者"，去"系统设置 → 隐私与安全性"里点"仍要打开"。

### 1.3 下载慢或下不动怎么办

```text
❌ 浏览器下到一半中断 → 换个浏览器（Edge/Chrome/Firefox），或用下载工具
❌ 公司网络拦截 → 换手机热点试，确认是公司拦截还是网络问题
❌ 提示"文件损坏" → 重新下载，别用旧缓存
❌ Mac 提示"磁盘空间不足" → 清理一下，App 加缓存至少留 2 GB
```

## 第二步：安装（Windows 和 Mac 分别讲）

### 2.1 Windows 安装

双击下好的 `.exe` 文件，跟着安装向导走：

```text
1. 弹出"是否允许此应用对设备进行更改" → 点"是"
2. 选择安装位置（默认装 C 盘就行，不用改）
3. 勾选"创建桌面快捷方式"（方便以后启动）
4. 点"安装"，等 1-3 分钟
5. 完成后勾选"立即启动 WorkBuddy"，点"完成"
```

**Windows 常见坑**：

```text
❌ "Windows 已保护你的电脑"（SmartScreen 拦截）
   → 点"更多信息" → "仍要运行"。这是因为 WorkBuddy 的数字签名 Windows 还没识别

❌ 杀毒软件拦截
   → 看清楚拦截原因，如果是误报，临时关闭杀毒软件再装，装完再开
   → 如果是公司电脑，先问 IT 加白名单

❌ 安装到一半提示"文件被占用"
   → 关掉所有可能用着这个文件的程序（浏览器、旧版 WorkBuddy），重试
```

### 2.2 Mac 安装

双击下好的 `.dmg` 文件：

```text
1. 弹出一个安装窗口，左边是 WorkBuddy 图标，右边是 Applications 文件夹图标
2. 用鼠标把 WorkBuddy 图标拖到右边的 Applications 上
3. 等待复制完成（10-30 秒）
4. 关掉安装窗口，打开"启动台"或"应用程序"文件夹，找到 WorkBuddy 点开
```

**Mac 常见坑**：

```text
❌ "无法打开 WorkBuddy，因为无法验证开发者"
   → 系统设置 → 隐私与安全性 → 滚到最下面找到"已阻止 WorkBuddy" → 点"仍要打开"
   → 第二次启动就不会再问了

❌ "WorkBuddy 已损坏，无法打开"
   → 这个通常是 Mac 的安全机制误判（特别是升级系统后）
   → 打开"终端"App，粘贴这行命令回车（把 WorkBuddy 换成你的实际 app 名）：
     sudo xattr -rd com.apple.quarantine /Applications/WorkBuddy.app
   → 输入你 Mac 的开机密码（输入时不显示，正常），回车，再开 App

❌ 苹果芯片 Mac 装了 Intel 版（或反过来）
   → 删掉重下对应版本。装错版本能开但会非常慢或闪退
```

## 第三步：第一次启动和登录

### 3.1 启动 App

Windows 双击桌面快捷方式，Mac 从启动台或应用程序文件夹打开。第一次启动可能要等 10-30 秒（App 在初始化），别急着点。

启动完成后，你会看到登录界面。

### 3.2 微信扫码登录（推荐）

老金强烈建议用微信扫码登——最快、不用记密码、后面多端接力也方便：

```text
1. 登录界面选"微信登录"或"扫码登录"
2. 屏幕上出现一个二维码
3. 打开手机微信 → 右上角"+" → "扫一扫"
4. 扫屏幕上的二维码
5. 手机上点"允许"或"确认登录"
6. 电脑端自动进入主界面
```

**扫码登不上怎么办**：

```text
❌ 二维码刷不出来 → 检查网络，或刷新二维码（通常右下角有刷新按钮）
❌ 手机扫了但电脑没反应 → 等 5-10 秒，或重新扫
❌ 提示"账号异常" → 换个登录方式（QQ、手机号），或重启 App 重试
```

### 3.3 其他登录方式

除了微信扫码，通常还有：

```text
- QQ 扫码：跟微信扫码类似，用 QQ App 扫
- 手机号登录：输入手机号收验证码
- 账号密码登录：如果你之前注册过腾讯云账号，可以直接用账号密码
```

第一次用，老金推荐微信扫码——简单、不用输密码、后面切手机端也方便。

### 3.4 新用户引导

第一次登进去，App 会弹一个新手引导（通常是 3-5 屏的介绍），老金建议你：

```text
✅ 耐心看完（每屏只停留 10 秒，了解整体能力）
✅ 跟着引导做第一个示例任务（App 通常会给你一个预设的体验任务）
✅ 看清楚"专家""技能""连接器"这几个入口分别在界面哪里
❌ 别急着跳过——引导里会告诉你核心功能的位置，跳过了后面找不到
```

引导走完后，你会进入 WorkBuddy 的**主界面**。这时候你已经登进来了，下一步跑通第一个任务验证 App 能用。

## 第四步：跑通第一个任务（验证 App 能用）

老金这一步不教你召唤复杂专家，只让你跑一个**最简单的对话**，确认 App、账号、网络都通。

### 4.1 找到对话入口

主界面上找一个**对话框**或**新建对话**按钮（位置以你本机为准，通常在中间或右下角）。

### 4.2 发一个最小任务

在对话框里粘贴这段话：

```text
你好，请用一句话介绍你自己，然后告诉我你能帮我做什么。
```

回车发送。

### 4.3 你会看到什么

```text
- 几秒内，AI 开始回复
- 回复包含：自我介绍 + 它能做的事（写文档、查资料、做表格、写代码等）
- 文字流畅、中文通顺
```

如果看到这个结果，恭喜你——**App、账号、网络、AI 模型链路全通了**。你已经可以用 WorkBuddy 了。

### 4.4 如果没跑通

```text
❌ 发出去没反应、一直转圈
   → 检查网络（开个网页试试）
   → 检查积分（下面第五步会讲怎么查）
   → 重启 App 重试

❌ 提示"积分不足"或"额度用完"
   → 你可能登的是免费版，额度用完了
   → 看第五步查积分，或等明天重置（免费版通常每日或每月重置）

❌ 回复是乱码或英文
   → 检查 App 语言设置（设置 → 语言 → 简体中文）
   → 重新发一次任务，前面加一句"请用中文回复"

❌ 提示"服务繁忙"或"请稍后再试"
   → 服务器临时压力，等 10 分钟再试
   → 换个时段（工作日白天通常比晚上流畅）
```

## 第五步：找到你的积分余额（很重要）

老金把这一步单独拎出来，是因为很多人第一天用就烧光免费额度还不知道为什么。**登进来第一件事就是搞清积分**。

### 5.1 积分是什么

**积分**就是 WorkBuddy 的"AI 干活能量额度"，类似游戏里的钻石。你每次让 AI 干活（对话、召唤专家、用技能、跑专家团）都扣积分。积分用完了任务就跑不动。

不同账号套餐每月给不同的积分额度（免费版少、专业版多），用完了要么等下月重置、要么加购。

### 5.2 积分在哪查

主界面找下面这几个地方（不同版本位置可能不同）：

```text
- 左下角或右上角的"我的"、"个人中心"、"账户"
- 设置（齿轮图标）→ 账户或订阅
- 鼠标悬停在你的头像上，有时会弹出积分余额
```

找到后，记下这三个数：

```text
1. 当前剩余积分
2. 本月总额度（如果你订了专业版）
3. 下次重置时间（积分什么时候补回来）
```

### 5.3 第一次试用怎么省积分

```text
✅ 先用免费额度摸清消耗速率（不同任务扣多少）
✅ 简单任务用直接对话，不要动不动召唤专家团（专家团是单专家 3-5 倍消耗）
✅ 长任务拆成小任务分次跑，避免一次烧光
✅ 看到积分快没了（剩 10% 左右），停下来看要不要加购或等重置
❌ 别一上来就跑复杂专家团任务（3-5 倍消耗很快烧光）
❌ 别开着后台自动化任务不管（会持续消耗）
```

## 第六步：装完后的安全自检

老金这一步是为你好——AI 助手能读你的文件、发你的消息，第一次装完必须做这几个检查：

### 6.1 看清 App 申请了什么权限

第一次启动时，App 可能申请这些权限，老金告诉你每个该不该给：

```text
- 文件访问权限：✅ 给（AI 要读你的文档才能干活）
- 麦克风权限：⚠️ 看需求（你要用语音输入就给，不用就不给）
- 摄像头权限：❌ 一般不用给（办公场景用不到）
- 通知权限：✅ 给（任务跑完要提醒你）
- 开机自启：⚠️ 看习惯（你想开机就用就开，不想就关）
```

### 6.2 第一次别接敏感账号

```text
❌ 第一次试用，别急着接工作邮箱（特别是公司敏感邮箱）
❌ 别急着连生产代码仓库（GitHub 生产项目）
❌ 别急着开自动化任务（怕后台乱跑）
✅ 先用公开或脱敏素材跑通，确认 App 行为可靠后再扩大
```

### 6.3 找到"退出登录"和"注销账号"在哪

以防万一，先找到这两个救命按钮在哪（通常在"设置 → 账户"里）：

```text
- 退出登录：临时不用时退出（保留账号和数据）
- 注销账号：彻底删除账号和所有数据（不可恢复，慎用）
```

知道这俩在哪，万一哪天不用了能干净撤出。

## 常见问题

**Q1：WorkBuddy 收费吗？不付费能用吗？**
有免费版，每月有有限积分额度，够你体验几轮。免费额度用完了要等重置或升级付费版。付费版（约 99 元/月起）积分多得多、模型更强。

**Q2：装了 WorkBuddy 还要装 CodeBuddy 吗？**
不用单独装。同一个账号、积分共享。你装了 WorkBuddy，编程需求可以切到它的 Coding Mode（看 WB-09）。如果你是重度编程用户，也可以单独装 CodeBuddy 专门的编程界面。

**Q3：手机上能用 WorkBuddy 吗？**
能。微信小程序搜 WorkBuddy，或关注它的公众号。手机端主要用来查看任务、远程触发、轻量交互，复杂任务还是桌面更顺手。详细看 WB-08 多端协同。

**Q4：Mac 上提示"已损坏"是不是真坏了？**
不是，是 Mac 安全机制误判。按本篇 2.2 节那个 `xattr` 命令处理一下就行。

**Q5：公司电脑装不上怎么办？**
先问 IT 能不能装、要不要加白名单。很多公司有安全软件拦截，不是 WorkBuddy 的问题。IT 同意了还装不上，把报错截图发 WorkBuddy 官方客服。

**Q6：登进来什么都没有，界面跟教程说的不一样？**
WorkBuddy 更新很快，界面会变。以你本机当前显示为准，按"找入口的逻辑"去找（比如找"专家"在哪、找"积分"在哪），而不是死记教程里的位置。

**Q7：积分扣得好快，正常吗？**
看你用什么任务。普通对话最便宜，单专家中等，专家团最贵（3-5 倍）。第一次试用别用专家团，先用直接对话和单专家摸清消耗。
