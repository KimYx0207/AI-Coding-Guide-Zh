## 开始之前：先确认你的环境

老金把环境清单放最前面，免得你装到一半才发现卡住：

```text
✅ 操作系统：Windows 10/11 x64，或官网下载页提供安装包的 macOS 版本与芯片
✅ Windows ARM64：先核对当前版本支持说明，不直接套用 x64 安装步骤
✅ 磁盘与内存：按当前安装要求留出空间，保存材料和生成成果还会占用额外容量
✅ 网络：能打开 WorkBuddy 官网和登录页；企业网络按公司的出口规则配置
✅ 登录方式：个人微信、手机号、邮箱等以官网当前弹窗为准，企业 SSO 按公司配置使用
✅ 安装权限：按系统实际提示处理；受管理的公司电脑先遵守 IT 的安装要求
```

> 💡 **企业内网用户先看这条**：如果你在公司电脑装，公司有严格的安全软件（比如 360 企业版、火绒企业版、深信服终端管理），装之前先问 IT 这几件事——允许不允许装、要不要加白名单、有没有代理设置。很多"装不上"的坑不是 WorkBuddy 的问题，是企业内网拦截。

## 第一步：下载安装包

> **2026-09-13 下载口径**：官网首页给的是最新版，直接从首页下就行。官方文档里那个「历史版本下载」页只归档到 v5.1.2（2026-06-17），**别拿它当最新版下载口**，截至当日，客户端已到 5.5.6（2026-09-10）。装完之后 App 会自己提示升级，跟着升即可。

### 1.1 去哪下载

打开浏览器（例如 Edge、Chrome 或 Firefox），直接进入 WorkBuddy 官网；需要搜索时，再用百度、必应等搜索引擎查找“WorkBuddy 腾讯”或“WorkBuddy 官网”。

> ⚠️ **认准官网**：直接打开 <https://www.workbuddy.cn/>，从官网的下载入口获取安装包。仅凭搜索结果的“官方”标识，或网址里出现 tencent、workbuddy 字样，不能确认网站身份；下载前核对浏览器地址栏中的完整域名。

进入官网后，找**下载**或**免费下载**按钮（通常在首页显眼位置）。官网会自动识别你的系统（Windows 还是 Mac），给你对应的安装包。

> 💡 **要不要先注册账号？** 下载安装包可以先做，打开 App 后再按官网登录页选择微信、手机号、邮箱等方式；企业 SSO 使用公司配置的入口。不要把微信扫码当成唯一账号方式。

### 1.2 选对版本

如果官网给了多个版本，老金告诉你怎么选：

```text
- Windows 用户：选择官网下载页提供的 Windows 安装包；不要仅凭扩展名把 .msi 当成便携版
- Mac 用户：看清芯片类型
   - 苹果芯片（M1/M2/M3/M4）：选 ARM 版或 Apple Silicon 版
   - Intel 芯片（老 Mac）：选 Intel 版或 x64 版
   - 不确定自己 Mac 是什么芯片？点左上角苹果图标 → "关于本机" → 看"芯片"那一栏
```

> 💡 **Mac 安装位置**：打开官网取得的 .dmg 文件，把 WorkBuddy 图标拖到 Applications 文件夹，复制完成后再从“应用程序”启动。遇到系统拦截时，先核对下载来源、芯片类型和完整提示，再按系统及官方安装说明处理；不把从安装镜像启动一概解释成“会丢权限”。

### 1.3 下载慢或下不动怎么办

```text
❌ 浏览器下到一半中断 → 换个浏览器（Edge/Chrome/Firefox），或用下载工具
❌ 公司网络拦截 → 换手机热点试，确认是公司拦截还是网络问题
❌ 提示"文件损坏" → 重新下载，别用旧缓存
❌ Mac 提示“磁盘空间不足” → 查看系统可用空间，按官网下载页的安装要求留足空间；练习材料、缓存和产物还会继续占用容量
```

## 第二步：安装（Windows 和 Mac 分别讲）

### 2.1 Windows 安装

双击下好的 `.exe` 文件，跟着安装向导走：

```text
1. 弹出"是否允许此应用对设备进行更改" → 点"是"
2. 选择安装位置（默认装 C 盘就行，不用改）
3. 勾选"创建桌面快捷方式"（方便以后启动）
4. 点"安装"，等 1-3 分钟
5. 完成后勾选"立即启动 WorkBuddy"，点"完成"
```

**Windows 常见坑**：

```text
❌ “Windows 已保护你的电脑”或安全软件拦截
   → 先核对下载来源、完整报错和安装包版本；不要只凭一条提示断定是数字签名未识别或误报
   → 公司电脑把报错交给 IT，按已批准的安装或白名单流程处理
   → 仍无法安装时查官方常见问题；不要为了跟练直接关闭所有防护

❌ 安装到一半提示"文件被占用"
   → 关掉所有可能用着这个文件的程序（浏览器、旧版 WorkBuddy），重试
```

### 2.2 Mac 安装

双击下好的 `.dmg` 文件：

```text
1. 弹出一个安装窗口，左边是 WorkBuddy 图标，右边是 Applications 文件夹图标
2. 用鼠标把 WorkBuddy 图标拖到右边的 Applications 上
3. 等待复制完成（10-30 秒）
4. 关掉安装窗口，打开"启动台"或"应用程序"文件夹，找到 WorkBuddy 点开
```

**Mac 常见坑**：

```text
❌ “无法打开 WorkBuddy，因为无法验证开发者”
   → 先确认安装包来自官网，保存完整提示并查官方 Mac 安装说明
   → 确认来源后，再按系统“隐私与安全性”提供的操作处理；受管理电脑按 IT 已批准流程执行，不保证下一次启动一定不再提示

❌ “WorkBuddy 已损坏，无法打开”
   → 先核对安装包来源、Mac 芯片类型和下载是否完整，再从官网重新下载
   → 仍有提示时保留完整报错，查官方 Mac 安装说明或请 IT/官方支持协助
   → 不能只凭这句话认定一定是误判；本教程不把移除隔离属性作为无条件安装步骤

❌ 安装包的芯片类型与 Mac 不一致
   → 在“关于本机”核对芯片，再从官网选择匹配的安装包；不要把能够启动、运行变慢或闪退当成所有装错版本都会出现的结果
```

## 第三步：第一次启动和登录

### 3.1 启动 App

Windows 双击桌面快捷方式，Mac 从启动台或应用程序文件夹打开。第一次启动可能要等 10-30 秒（App 在初始化），别急着点。

启动完成后，你会看到登录界面。

### 3.2 微信扫码登录（推荐）

老金强烈建议用微信扫码登——最快、不用记密码、后面多端接力也方便：

```text
1. 在客户端点击“登录”，浏览器会打开 WorkBuddy 官网登录页
2. 核对地址栏为 workbuddy.cn，在登录弹窗中阅读并勾选服务协议与隐私政策
3. 选择微信登录，用手机微信扫一扫扫描网页中的二维码
4. 在手机上确认登录
5. 网页显示登录成功后，返回 WorkBuddy 客户端
```

**扫码登不上怎么办**：

```text
❌ 二维码刷不出来 → 检查网络，或刷新二维码（通常右下角有刷新按钮）
❌ 手机扫了但电脑没反应 → 等 5-10 秒，或重新扫
❌ 提示"账号异常" → 在当前官网登录弹窗中检查可用的手机号、邮箱或 SSO 登录方式；仍失败时按官网提示排查账号
```

### 3.3 其他登录方式

官方安装指南还列出了**手机号、邮箱、SSO**等登录方式，是否可用以官网当前登录弹窗和你的账号条件为准。教程不把 QQ 扫码或腾讯云账号密码当成固定入口；企业 SSO 按公司已配置的方式使用。

第一次用，老金推荐微信扫码——简单、不用输密码、后面切手机端也方便。

### 3.4 新用户引导

第一次登进去，App 会弹一个新手引导（通常是 3-5 屏的介绍），老金建议你：

```text
✅ 耐心看完（每屏只停留 10 秒，了解整体能力）
✅ 跟着引导做第一个示例任务（App 通常会给你一个预设的体验任务）
✅ 看清楚"专家""技能""连接器"这几个入口分别在界面哪里
❌ 别急着跳过——引导里会告诉你核心功能的位置，跳过了后面找不到
```

引导走完后，你会进入 WorkBuddy 的**主界面**。这时候你已经登进来了，下一步跑通第一个任务验证 App 能用。

## 第四步：跑通第一个任务（验证 App 能用）

老金这一步不教你召唤复杂专家，只让你跑一个**最简单的对话**，确认 App、账号、网络都通。

### 4.1 找到对话入口

主界面上找一个**对话框**或**新建对话**按钮（位置以你本机为准，通常在中间或右下角）。

### 4.2 发一个最小任务

在对话框里粘贴这段话：

```text
你好，请用一句话介绍你自己，然后告诉我你能帮我做什么。
```

回车发送。

### 4.3 你会看到什么

```text
- 几秒内，AI 开始回复
- 回复包含：自我介绍 + 它能做的事（写文档、查资料、做表格、写代码等）
- 文字流畅、中文通顺
```

如果看到这个结果，恭喜你——**App、账号、网络、AI 模型链路全通了**。你已经可以用 WorkBuddy 了。

### 4.4 如果没跑通

```text
❌ 发出去没反应、一直转圈
   → 检查网络（开个网页试试）
   → 检查积分（下面第五步会讲怎么查）
   → 重启 App 重试

❌ 提示"积分不足"或"额度用完"
   → 你可能用的是体验版，额度用完了
   → 看第五步查当前余额、资源包有效期与补充时间；WB-10 保留了旧套餐快照，本次没有取得当日积分说明，不把 500 积分或自然月重置当成当前保证

❌ 回复是英文
   → 在当前任务补充“请用中文回复”；界面语言可到头像 → 设置 → 通用中检查

❌ 回复有乱码
   → 保存报错或异常片段，核对输入文件的编码；界面语言设置不能保证解决文件编码问题

❌ 提示"服务繁忙"或"请稍后再试"
   → 服务器临时压力，等 10 分钟再试
   → 保留失败提示和发生时间，查看官方服务信息；仍失败时通过帮助与反馈提交，不按白天或晚上保证更顺畅
```

## 第五步：找到你的积分余额（很重要）

老金把这一步单独拎出来，是因为很多人第一天用就烧光免费额度还不知道为什么。**登进来第一件事就是搞清积分**。

### 5.1 积分是什么

**积分**就是 WorkBuddy 的"AI 干活能量额度"，类似游戏里的钻石。你每次让 AI 干活（对话、召唤专家、用技能、跑专家团）都扣积分。积分用完了任务就跑不动。

不同套餐的额度、积分有效期和补充时间可能不同。先查看账号页面的当前权益与分类明细；余额不足时，按页面判断是等待套餐补充，还是需要购买适用的资源包。历史金额和额度见 WB-10，不能代替当前权益。

### 5.2 积分在哪查

点击左侧栏底部的头像，选择**查看积分余额**；也可进入**设置 → 套餐与积分**查看当前套餐与用量。5.4.7 的更新日志把该页称为「订阅和用量」，本机仍用这个名称时进入该页即可。

没找到时，先从**头像 → 检查更新**核对版本，再查官方系统设置说明，不必依次猜“我的”“账户”或悬停头像。

找到后，记下这三个数：

```text
1. 当前剩余积分
2. 本月总额度（如果你订了标准版或更高档）
3. 下次重置时间（积分什么时候补回来）
```

### 5.3 第一次试用怎么省积分

```text
✅ 先用免费额度摸清消耗速率（不同任务扣多少）
✅ 简单任务先用直接对话；需要多角色分工时再试专家团，观察实际积分消耗
✅ 长任务拆成小任务分次跑，避免一次烧光
✅ 看到积分快没了（剩 10% 左右），停下来看要不要加购或等重置
❌ 别一上来就跑复杂专家团任务，先确认任务范围和可接受的消耗
❌ 别开着后台自动化任务不管（会持续消耗）
```

## 第六步：装完后的安全自检

老金这一步是为你好——AI 助手能读你的文件、发你的消息，第一次装完必须做这几个检查：

### 6.1 看清 App 申请了什么权限

第一次启动时，App 可能申请这些权限，老金告诉你每个该不该给：

```text
- 文件访问：先选有权使用的练习目录；遇到授权提示时核对具体路径和操作，再决定是否允许
- 麦克风：需要语音输入时再授权，不用时可保持关闭
- 摄像头：本篇文本练习不需要；其他任务确实要使用时再检查用途
- 通知：需要完成提醒时按系统提示开启，并用小任务验证是否收到
- 开机自启：按使用习惯决定；远程助理还要确认登录状态、网络和 App 实际在线
```

### 可选：用一句话试语音输入

5.6.0 加入语音录入的实时反馈，延长了最长录音时长，也改善了录音过程中手动编辑的衔接。官方日志没有公布具体时长，本次按一个短句试跑：

1. 在当前对话中打开语音输入；系统询问麦克风权限时，只在准备录音的情况下允许。
2. 说一句虚构内容：“星桥读书会周五讨论一本书。”观察输入框是否实时出现识别文字。
3. 在结束录音前检查文字，试着手动修正“星桥”两个字或补一个标点，再按客户端当前录音控件结束。核对手动改过的内容是否保留；没有识别文字时先检查麦克风授权与设备，不反复发送空消息。
4. 确认文字正确后，在识别文字后补充“请把这句话整理成一句活动说明”，再发送这条完整消息。看到回复后，对照发送的文字核对名称和时间。

这里只练文字录入，不把录音延长解释成无限录音，也没有给出未经核实的按钮位置或最长秒数。不用语音时，继续粘贴文本即可完成本章主线。

### 6.2 第一次别接敏感账号

```text
❌ 第一次试用，别急着接工作邮箱（特别是公司敏感邮箱）
❌ 别急着连生产代码仓库（GitHub 生产项目）
❌ 别急着开自动化任务（怕后台乱跑）
✅ 先用公开或脱敏素材跑通，确认 App 行为可靠后再扩大
```

### 6.3 找到"退出登录"和"注销账号"在哪

这次只认清入口，不需要实际注销：

- **退出登录**：点击左侧栏底部的头像，在用户菜单中选择“退出登录”，用于退出当前账号或切换账号。
- **注销账号**：桌面客户端没有直接注销按钮。按 [官方账号注销说明](https://www.workbuddy.cn/docs/workbuddy/Account-Cancellation)，从头像进入**个人主页 → 前往管理中心 → 账号设置**，在网页底部查看注销入口。

注销申请提交后有 **15 天冷静期**，期间账号无法登录；需要撤销时联系官方客服。期满后数据永久删除，关联的 CodeBuddy 账号也会同步注销。注销不会自动退款或关闭自动续费，付费资源、续费签约和企业创建者身份等阻断项要按官方说明先处理。日常暂时不用选退出登录，别把注销当成排障步骤。

## 常见问题

**Q1：WorkBuddy 收费吗？不付费能用吗？**
本系列在 WB-10 保留了 2026-09-14 的体验版和付费档报价快照。当前是否有免费额度、额度多少、可用哪些模型，先到“查看积分余额”或“套餐与积分”核对；本次没有取得当日定价与积分正文，不能保证旧额度够跑几轮，也不把付费等同于所有任务效果更好。

**Q2：装了 WorkBuddy 还要装 CodeBuddy 吗？**
本篇练习不要求另装 CodeBuddy。你装了 WorkBuddy，编程需求可以切到它的 Coding Mode（看 WB-09）；如果需要 CodeBuddy 专门的编程界面，也可以单独安装。两产品的登录、订阅和可用积分分别按当前账户页面核对，不在这里保证全部共享。

**Q3：手机上能用 WorkBuddy 吗？**
可以使用 WorkBuddy 原生移动 App：从官网或桌面“连接移动端”面板进入，登录同一账号后选择已允许连接的电脑，再查看、继续或停止对应任务。微信助理、企业微信和小程序是其他入口，分别按各自流程配置；公众号用于查看产品动态。具体跟练见 [WB-08](./WB-08-WorkBuddy多端协同完整指南.md)。

**Q4：Mac 上提示"已损坏"是不是真坏了？**
不能只凭提示判断。先按 2.2 节检查下载来源、芯片版本和安装包完整性；仍失败就保留报错查官方说明，不把移除隔离属性当成所有情况的解决办法。

**Q5：公司电脑装不上怎么办？**
先问 IT 能不能装、要不要加白名单。很多公司有安全软件拦截，不是 WorkBuddy 的问题。IT 同意了还装不上，把报错截图发 WorkBuddy 官方客服。

**Q6：登进来什么都没有，界面跟教程说的不一样？**
WorkBuddy 更新很快，界面会变。以你本机当前显示为准，按"找入口的逻辑"去找（比如找"专家"在哪、找"积分"在哪），而不是死记教程里的位置。

**Q7：积分扣得好快，正常吗？**
先看「订阅和用量」里的实际消耗，再回顾用了什么模型、任务有多复杂、是否反复重跑。不要按专家数量预估固定倍数；先用小任务摸清预算，再扩大任务规模。
