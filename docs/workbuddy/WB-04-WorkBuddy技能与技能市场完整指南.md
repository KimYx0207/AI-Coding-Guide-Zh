# WB-04 WorkBuddy 技能与技能市场：让 AI 会干具体的活

老金写这篇教程的目的——让你学会用**技能**扩展 WorkBuddy 的能力。专家决定 AI"以什么身份思考"，技能决定 AI"能干哪些具体动作"。学完这篇，你的 WorkBuddy 就能发邮件、查股价、读写文件、调用各种外部工具，不再只是个会聊天的助手。

## 先搞清：技能是什么、跟专家啥区别

老金每次讲技能都有人搞混它和专家。先用一个比喻讲清：

```text
专家 = 一个有职业身份的人（比如秘书小王）
技能 = 这个人手里会用的工具（比如打印机、扫描仪、Excel）
```

专家可能已经带有方法和工具，技能则把一类流程整理成可以复用的说明和能力。是否能操作文件、邮箱或其他服务，还要看实际工具、依赖和授权；不要求每个任务都先安装新技能。

**对应到 WorkBuddy**：

| | 专家 | 技能 |
|---|---|---|
| **解决什么** | 用什么身份思考 | 能做什么动作 |
| **例子** | "办公写作专家" | "发邮件""查股价""读写本地文件" |
| **能单独用吗** | 能（召唤就有产出） | 通常要配合专家或对话用 |

技能把某类任务的方法、说明和必要工具组织成可复用能力。比如写邮件的方法可以复用，但是否真的能发邮件，还要看邮件服务是否已连接、该能力有哪些依赖，以及你是否已授权发送。安装一个名字叫“发邮件”的技能，不等于邮箱已经接通。

准备清单：

```text
✅ WB-03 学完，会召唤专家
✅ 账号有可用积分；安装说明、AI 用量和依赖服务的费用分别查看
✅ 至少想清楚一个真实需求（比如"我想让 AI 帮我发邮件"）
```

## 第一步：逛技能市场，看看有什么（10 分钟）

### 1.1 进入技能市场

在左侧栏打开**专家·技能·连接器 → 技能**页签。一级菜单中没看到时先检查“更多”；也可以右键左侧菜单查看自定义分组。进入后，按当前页面区分可安装技能和已安装技能：

```text
- 技能市场：所有可装的技能，按分类展示，可一键安装
- 已安装：你已经装的技能，可启用/禁用/卸载
```

### 1.2 技能市场里大概有什么

WorkBuddy 提供现成技能，也支持导入社区技能或用自然语言创建技能。市场总量与内置数量不是同一个概念，下面按用途举例，能否安装要查看当前卡片及依赖说明：

```text
📝 办公类：
   - 办公文档四件套（Word/Excel/PPT/PDF 读写）
   - 邮件收发（QQ 邮箱、网易邮箱等）
   - 日历提醒（添加日程、定时提醒）

🔍 信息类：
   - 网页搜索（实时查互联网）
   - 股价查询、汇率查询、天气查询
   - 新闻聚合、热点监控

📁 文件类：
   - 本地文件读写
   - 文件格式转换（PDF↔Word、图片↔PDF）
   - 文件批量重命名

🎨 创作类：
   - 图片生成、图片编辑
   - 视频下载、视频转录
   - 海报设计、LOGO 设计

🛠️ 开发类：
   - 代码运行、代码审查
   - 数据库查询
   - API 调用工具

📚 知识类：
   - 笔记软件对接（Obsidian、Notion）
   - 知识库检索
```

### 1.3 怎么挑技能

老金的挑技能三原则：

```text
1. 按需求挑：先想"我经常干哪件重复活"，再去找对应技能，别盲目装
2. 看来源与依赖：确认提供方、安装说明、所需账号或外部服务符合你的任务
3. 看维护信息：页面若给出更新时间、版本记录或用户反馈，就作为参考；没有这些栏目时，先用小材料验证，不猜评分按钮
```

> 💡 **零成本技能优先**：技能市场有一批标注"零成本"或"免费"的技能，先用这批练手，摸清机制再考虑付费的。老金整理过一份"零成本精选 10 个"清单（含办公文档四件套、网页搜索、文件读写等），新手优先装这些。

### 1.4 卡住了怎么办

```text
❌ 找不到"技能市场"入口
   → 先找“专家·技能·连接器 → 技能”，并检查“更多”
   → 右键左侧菜单查看自定义分组；若当前应用没提供技能能力，回到可用的通用任务再检查

❌ 技能市场是空的或加载不出来
   → 检查网络，刷新页面
   → 你登的可能是企业版，企业版技能市场由管理员控制，问 IT

❌ 搜不到想要的技能
   → 换关键词（"发邮件"不行就搜"邮件""email""smtp"）
   → 实在没有可以自己装自定义技能（看第四步）
```

## 第二步：装一个技能并跑通（15 分钟）

### 2.1 第一次装：装"网页搜索"技能

老金带你装一个所有人都会用到的——**网页搜索**技能。这个练习用搜索技能取得网页资料，再逐条核对来源和日期；本机若已有其他搜索能力，也可以先查当前任务提供了哪些工具。联网查询仍可能遗漏或误引，不能因为安装完成就保证答案实时、完整。

```text
1. 进入技能市场
2. 搜索"网页搜索"或"联网搜索"
3. 查看卡片来源、能力和依赖，选择适合本次任务的技能，按当前页面完成安装
4. 等几秒，安装完成，跳到"已安装"区域
5. 确认它是"已启用"状态（如果是"已禁用"，点一下切换）
```

### 2.2 跑通第一个技能任务

回到对话界面，召唤任何一位专家（或直接对话），发这段：

```text
帮我查一下 [某个最近的新闻、最近发布的某个产品、某个公众人物的最新动态]，
用网页搜索技能，给我：
1. 这件事的核心事实（时间、人物、发生了什么）
2. 3 条不同来源的报道链接
3. 一段话总结各方观点

要实时信息，不要凭记忆答。
```

### 2.3 你会看到什么

```text
- AI 调用"网页搜索"技能，实时拉取最新信息
- 产出包含：核心事实、来源链接、观点总结
- 逐条点开来源链接，核对网页内容、发布日期和支持的事实；调用过搜索技能，仍可能误引或生成无效链接
```

确认调用记录和来源都能对应到本次问题后，再换成自己需要查询的事项。看到了链接但打不开，或日期不符合要求时，先指出具体缺口，让它重新查询。

### 可选练习：让浏览器操作网页

网页搜索用来查资料与来源，浏览器操作可以打开页面、滚动、点击、展开内容和截图；WB-09 的内置浏览器还可以预览你开发的网页。先按任务选用，检查实际操作记录。

[5.6.0 官方更新日志](https://www.workbuddy.cn/docs/workbuddy/Changelog-5.6.0)确认 **Browser Use** 已适配 **Edge 加载项商店和 QQ 浏览器**。日志没有给出独立安装步骤，这里先说明兼容范围。若要完成一次有官方说明的浏览器技能练习，可以使用安装名为 `agent-browser`、来源为 SkillHub 的 **Agent Browser**；官方把它单独列为技能，本节按这个名称安装和验收，不能据此断言它就是日志里的 Browser Use。

1. 在技能页查找 `agent-browser`，核对 SkillHub 来源、权限与依赖，再按页面安装并启用。已有同名技能时先查提供方；找不到时保留提示，按官方技能说明核对，不安装来源不明的同名包。
2. 在一个练习任务中发送：“使用 agent-browser 打开 https://www.workbuddy.cn/docs/workbuddy/Changelog ，滚动找到 5.6.0 的条目，整理前五项新增或恢复的能力，写出页面中的发布日期，并保存一张该段页面截图。只访问这个公开页面，不登录、不提交表单。”
3. 查看实际工具过程是否打开并读取了这个页面。核对摘要中的版号和日期，打开截图检查内容是否对应同一段；只看到一段文字回复、没有操作记录或截图时，还不能算这次浏览器练习跑通。

这项练习只要求读取公开页面并截图，结果与积分按当前任务记录核对，没有把它写成实际执行结果。操作范围和示例见 [官方 Agent Browser 说明](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/WorkBuddy-Zero-Cost-Skill-Top-10/Agent-Browser)；该功能页未标首次发布日期。

### 2.4 技能没跑通怎么办

```text
❌ AI 没调用技能，还是凭记忆答
   → 检查技能是不是真的"已启用"（已安装≠已启用）
   → 在提问里明确点名："请使用网页搜索技能查..."
   → 查看技能说明中的适用范围与依赖，核对任务实际启用了该技能；只有说明明确依赖某个专家或应用时，再切换到对应入口

❌ 技能调用失败 / 报错
   → 看错误提示（通常会说"权限不足""网络超时""配额用完"）
   → 权限不足：按报错核对执行权限、工作目录或依赖服务的授权；没有独立技能设置面板时，按技能说明处理
   → 网络超时：重试，或换时段
   → 配额用完：查对应服务给出的额度与重置时间，不默认所有免费技能都等明天恢复

❌ 调用了但结果不对
   → 核对任务输入、技能说明和实际调用记录；页面提供用户反馈时再参考，不能因结果错误就断定技能本身有问题
   → 换个同类技能试（市场通常有多个相似技能）
```

## 第三步：管理你装的技能（启停、卸载、排序）

### 3.1 别一装就全开——按需启用

老金这条建议很重要：**装了不等于要一直开**。

```text
✅ 按本次任务启用需要的技能，并检查实际调用记录
✅ 发现能力重叠或调错时，缩小启用范围再试，不用固定技能数量保证效果
✅ 技能开关不等于定时任务；是否持续执行和消耗，要看任务与后台运行记录
```

### 3.2 启用 / 禁用 / 卸载

打开**已安装**区域，用技能开关启用或停用；停用会保留技能包，但模型不再自动调用它。开关状态会跨设备同步，不能据此推断技能文件和本地依赖也已同步。

同名技能先看**来源和包**，再看是否安装。5.6.2 修复了不同来源的同名技能误标已安装，以及套件里的技能被误关；仅凭名字相同不能决定覆盖或卸载。

要检查开关是否影响当前会话，先选一个已经用公开练习材料调用过的技能，记下实际调用名称；关闭它后，在同一会话发一个同类小请求，核对是否还自动调用这项技能。重新启用后，再用小请求检查恢复。若技能属于套件，分别核对套件与成员的状态，先保留已有结果；已有命令是否仍运行，也要查看任务状态，不能把配置开关当成停止按钮。5.6.0 修复了套件启停在当前会话不生效的问题，正常操作不需要为了更新开关再造一个任务。

不再需要时使用卸载，也可批量卸载。先核对勾选对象再确认，随后检查已安装列表和任务中的选择。卸载会移除技能及其开关记录，外部服务授权仍需另行管理。

### 3.3 检查展示顺序与实际调用

5.6.0 起客户端会提醒长时间未使用的插件或技能，可从提醒卡片关闭闲置能力。先核对是哪项能力、近期任务是否仍需要它，再关闭；需要时回已安装列表重新启用。

如果当前页面提供排序，可以按自己的查找习惯整理；不要从展示顺序推断模型会优先调用前面的技能。任务中明确需要的能力，再检查实际调用记录，更容易判断是否选对工具。

## 第四步：进阶——自定义技能

广场上没有的技能，你可以自己装。

### 4.1 什么时候要自定义

```text
✅ 公司内部系统（自建的 OA、CRM、ERP）没有现成技能
✅ 特定 API（你们家产品的接口）想给 AI 调用
✅ 特定工作流（每天导某个报表、每周汇总某个数据）想自动化
✅ 技术用户想跑自己写的脚本
```

### 4.2 怎么装自定义技能

先进入**专家·技能·连接器 → 技能**，点击**添加技能**，按手头材料选择一条路径：

1. **上传技能**：已有技能包时，先读来源、结构和依赖说明，再拖入文件或点击**选择文件**导入。系统会自动完成配置；安装后仍要核对启用状态和依赖，用小任务验证。
2. **查找技能**：描述要完成的任务，让 WorkBuddy 查找合适技能。检查推荐的提供方和依赖，再决定是否安装。
3. **创建技能**：说明想复用的流程、输入、输出和限制，让 WorkBuddy 生成技能。先用练习材料试跑，确认结果再日常使用。

本课不要求新增外部账号或调用付费 API。技能生成或导入完成，不等于依赖的内部服务已经接通。操作参考 [官方技能说明](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)。

### 4.3 自定义技能的安全注意

```text
🚫 别装来路不明的技能包（可能含恶意代码）
🚫 别给技能超过它需要的权限（一个发邮件的技能不该能读你全盘文件）
✅ 自定义技能先在测试任务里跑，确认行为再纳入日常
✅ 涉及公司系统的技能，先问 IT 同意
```

## 第五步：技能 + 专家 + 连接器的组合玩法

老金这一步给你看一个完整组合，让你理解技能在整个 WorkBuddy 体系里的位置。

### 5.1 一个真实场景：自动汇报竞品动态

假设你想让 WorkBuddy 每天早上帮你出一份"竞品动态简报"，需要：

```text
1. 专家：选"市场调研专家"（决定身份和思考方式）
2. 技能：装"网页搜索"（让它能查最新信息）
3. 连接器：接"QQ 邮箱"或"腾讯文档"（让它能把结果发给你或存到文档）
4. 自动化：设一个定时任务（每天 9 点自动跑）——看 WB-07
```

四件东西各司其职：

```text
专家   = "谁来干"
技能   = "用什么工具干"
连接器 = "干完结果送哪去"
自动化 = "什么时候自动干"
```

### 5.2 这套组合的产出

任务与通知通道都已配置并验证后，可以按约定周期生成简报。下面仅展示格式，A/B 公司、事件和数字均为虚构，没有实际搜索或发送：

```text
竞品动态简报 - 2026年8月6日

■ A 公司
  - 昨日发布新产品 X（来源：官网）
  - 融资消息（来源：36Kr）

■ B 公司
  - 高管变动（来源：脉脉）
  - 价格下调 10%（来源：竞品监控）

■ 老金的建议
  - 关注 A 公司新产品对我们 Q4 的冲击
  - B 公司降价可能引发价格战，建议提前备好应对话术
```

先逐条核对来源、日期和结论，再观察几次运行记录，判断这套组合是否省下了整理时间。

## 常见问题

**Q1：技能要钱吗？**
分开看三件事：安装时页面是否收费、AI 执行任务的积分，以及技能依赖的外部服务是否另收费。不要看到“免费”就推断全部环节零成本，也不把所有技能都当成单独售卖；先读当前卡片与依赖说明，再看实际用量。

**Q2：装的技能越多越好吗？**
按任务选需要的能力即可。出现能力重叠或调用错误时，缩小启用范围并检查记录，再决定是否增加技能；本教程不把固定数量当作保证效果的阈值。

**Q3：技能和专家必须配合用吗？**
不必先召唤专家才能使用技能。按任务启用需要的技能，查看说明是否依赖某个应用、工具或账号；需要岗位方法时再选择对应专家。组合后的效果仍要用同一份材料核对。

**Q4：技能会过期失效吗？**
会。技能依赖的外部服务变了（比如某个网站改版了），技能可能失效。所以挑技能要看更新时间，长期不更新的别装。

**Q5：我能改已装技能的行为吗？**
看当前技能提供了哪些配置说明和可编辑内容。没有“设置/权限”面板时，不能靠改一个按钮调整所有访问范围；深度修改还要核对技能文件、依赖服务与执行权限，先在独立练习任务验证。

**Q6：技能调用的数据安全吗？**
技能可能运行脚本、调用工具或依赖外部服务，不能保证每个能力都有独立权限弹窗。先核对来源、工作空间、执行权限和服务授权，再用练习材料试跑并检查记录；企业治理能力按所购版本确认，见 WB-10。

**Q7：技能市场有上万个技能，挑不过来怎么办？**
先按需求查找，查看来源、依赖和当前提供的维护信息。选一个小任务试跑，能完成并核对结果后再加其他技能，不把评分和评论当成每个版本都有的栏目。
