# WB-04 WorkBuddy 技能与技能市场：让 AI 会干具体的活

老金写这篇教程的目的——让你学会用**技能**扩展 WorkBuddy 的能力。专家决定 AI"以什么身份思考"，技能决定 AI"能干哪些具体动作"。学完这篇，你的 WorkBuddy 就能发邮件、查股价、读写文件、调用各种外部工具，不再只是个会聊天的助手。

## 先搞清：技能是什么、跟专家啥区别

老金每次讲技能都有人搞混它和专家。先用一个比喻讲清：

```text
专家 = 一个有职业身份的人（比如秘书小王）
技能 = 这个人手里会用的工具（比如打印机、扫描仪、Excel）
```

一个人（专家）再厉害，没工具也只能动嘴。装上工具（技能）才能真干活——打印文件、扫描合同、做表格。

**对应到 WorkBuddy**：

| | 专家 | 技能 |
|---|---|---|
| **解决什么** | 用什么身份思考 | 能做什么动作 |
| **例子** | "办公写作专家" | "发邮件""查股价""读写本地文件" |
| **能单独用吗** | 能（召唤就有产出） | 通常要配合专家或对话用 |

简单说：你召唤一个办公写作专家，让它帮你写邮件——它能写出来，但发不出去。装上"发邮件"技能后，它就能直接帮你把邮件发到 QQ 邮箱。

**技能是什么**（老金翻译成大白话）：就是一组封装好的小程序（脚本和工作流），让 AI 在你授权下完成某个具体动作。

准备清单：

```text
✅ WB-03 学完，会召唤专家
✅ 账号有积分（装技能免费，用技能消耗积分）
✅ 至少想清楚一个真实需求（比如"我想让 AI 帮我发邮件"）
```

## 第一步：逛技能市场，看看有什么（10 分钟）

### 1.1 进入技能市场

主界面找**技能**或**技能市场**入口（通常在左侧栏或顶部，跟"专家"并列）。点进去你会看到两个区域：

```text
- 技能市场：所有可装的技能，按分类展示，可一键安装
- 已安装：你已经装的技能，可启用/禁用/卸载
```

### 1.2 技能市场里大概有什么

技能市场上有上万个技能（还在增长），老金按用途分几类给你认认：

```text
📝 办公类：
   - 办公文档四件套（Word/Excel/PPT/PDF 读写）
   - 邮件收发（QQ 邮箱、网易邮箱等）
   - 日历提醒（添加日程、定时提醒）

🔍 信息类：
   - 网页搜索（实时查互联网）
   - 股价查询、汇率查询、天气查询
   - 新闻聚合、热点监控

📁 文件类：
   - 本地文件读写
   - 文件格式转换（PDF↔Word、图片↔PDF）
   - 文件批量重命名

🎨 创作类：
   - 图片生成、图片编辑
   - 视频下载、视频转录
   - 海报设计、LOGO 设计

🛠️ 开发类：
   - 代码运行、代码审查
   - 数据库查询
   - API 调用工具

📚 知识类：
   - 笔记软件对接（Obsidian、Notion）
   - 知识库检索
```

### 1.3 怎么挑技能

老金的挑技能三原则：

```text
1. 按需求挑：先想"我经常干哪件重复活"，再去找对应技能，别盲目装
2. 看评分和评论：技能市场通常有评分，挑高分的、评论多的
3. 看更新时间：优先选最近 1-3 个月还在更新的，长期不更新的可能失效
```

> 💡 **零成本技能优先**：技能市场有一批标注"零成本"或"免费"的技能，先用这批练手，摸清机制再考虑付费的。老金整理过一份"零成本精选 10 个"清单（含办公文档四件套、网页搜索、文件读写等），新手优先装这些。

### 1.4 卡住了怎么办

```text
❌ 找不到"技能市场"入口
   → 可能在"应用""扩展""插件"这类菜单下（不同版本叫法不同）
   → 用 App 内的搜索功能直接搜"技能"

❌ 技能市场是空的或加载不出来
   → 检查网络，刷新页面
   → 你登的可能是企业版，企业版技能市场由管理员控制，问 IT

❌ 搜不到想要的技能
   → 换关键词（"发邮件"不行就搜"邮件""email""smtp"）
   → 实在没有可以自己装自定义技能（看第四步）
```

## 第二步：装一个技能并跑通（15 分钟）

### 2.1 第一次装：装"网页搜索"技能

老金带你装一个所有人都会用到的——**网页搜索**技能。装完你的 WorkBuddy 就能实时查互联网信息，不再受训练数据截止时间限制。

```text
1. 进入技能市场
2. 搜索"网页搜索"或"联网搜索"
3. 找到评分高的那个，点"安装"或"一键安装"
4. 等几秒，安装完成，跳到"已安装"区域
5. 确认它是"已启用"状态（如果是"已禁用"，点一下切换）
```

### 2.2 跑通第一个技能任务

回到对话界面，召唤任何一位专家（或直接对话），发这段：

```text
帮我查一下 [某个最近的新闻、最近发布的某个产品、某个公众人物的最新动态]，
用网页搜索技能，给我：
1. 这件事的核心事实（时间、人物、发生了什么）
2. 3 条不同来源的报道链接
3. 一段话总结各方观点

要实时信息，不要凭记忆答。
```

### 2.3 你会看到什么

```text
- AI 调用"网页搜索"技能，实时拉取最新信息
- 产出包含：核心事实、来源链接、观点总结
- 链接是真的（你可以点开核对），不是 AI 编的
```

如果你看到这些，恭喜——你的 WorkBuddy 已经从"只会凭记忆答"升级到"能查实时信息"了。

### 2.4 技能没跑通怎么办

```text
❌ AI 没调用技能，还是凭记忆答
   → 检查技能是不是真的"已启用"（已安装≠已启用）
   → 在提问里明确点名："请使用网页搜索技能查..."
   → 有些技能要配合特定专家用，换个专家试

❌ 技能调用失败 / 报错
   → 看错误提示（通常会说"权限不足""网络超时""配额用完"）
   → 权限不足：去技能设置里授权
   → 网络超时：重试，或换时段
   → 配额用完：免费技能也有调用频率限制，等明天

❌ 调用了但结果不对
   → 技能本身可能有问题，看评论是不是别人也吐槽
   → 换个同类技能试（市场通常有多个相似技能）
```

## 第三步：管理你装的技能（启停、卸载、排序）

### 3.1 别一装就全开——按需启用

老金这条建议很重要：**装了不等于要一直开**。

```text
✅ 只在用的时候启用：写邮件时开"邮件"技能，平时关掉
✅ 同时启用的技能控制在 5-10 个：太多会干扰 AI 判断（它不知道该调哪个）
✅ 用完就关：避免后台误触发、消耗积分
```

### 3.2 启用 / 禁用 / 卸载

在"已安装"区域，每个技能卡片上通常有三个操作：

```text
- 启用/禁用切换：临时开关，不删技能，下次要用再开
- 卸载：彻底删除（支持批量卸载）
- 设置/权限：配置这个技能能访问什么、不能访问什么
```

### 3.3 技能排序（重要程度排序）

有些版本支持技能排序——把最常用的拖到前面。为什么要排？因为 AI 同时看到多个技能时，会按顺序优先尝试排前面的。**把核心技能放前面，避免 AI 调错**。

## 第四步：进阶——自定义技能

广场上没有的技能，你可以自己装。

### 4.1 什么时候要自定义

```text
✅ 公司内部系统（自建的 OA、CRM、ERP）没有现成技能
✅ 特定 API（你们家产品的接口）想给 AI 调用
✅ 特定工作流（每天导某个报表、每周汇总某个数据）想自动化
✅ 技术用户想跑自己写的脚本
```

### 4.2 怎么装自定义技能

```text
方式一：上传本地技能包
   1. 找"上传技能""自定义技能""本地安装"入口
   2. 把你准备好的技能包（通常是个压缩文件）拖进去
   3. 系统自动配置，装完就能用

方式二：让 WorkBuddy 帮你生成
   1. 在对话里说："我想做一个技能，能帮我 [做某件事]"
   2. WorkBuddy 会反问细节，跟它对清楚需求
   3. 它帮你生成技能，你确认后保存
```

> ⚠️ **注意**：自定义技能需要一定技术基础。如果你完全不懂代码，先用方式二让 WorkBuddy 帮你生成。方式一适合有技术同事支持的团队。

### 4.3 自定义技能的安全注意

```text
🚫 别装来路不明的技能包（可能含恶意代码）
🚫 别给技能超过它需要的权限（一个发邮件的技能不该能读你全盘文件）
✅ 自定义技能先在测试任务里跑，确认行为再纳入日常
✅ 涉及公司系统的技能，先问 IT 同意
```

## 第五步：技能 + 专家 + 连接器的组合玩法

老金这一步给你看一个完整组合，让你理解技能在整个 WorkBuddy 体系里的位置。

### 5.1 一个真实场景：自动汇报竞品动态

假设你想让 WorkBuddy 每天早上帮你出一份"竞品动态简报"，需要：

```text
1. 专家：选"市场调研专家"（决定身份和思考方式）
2. 技能：装"网页搜索"（让它能查最新信息）
3. 连接器：接"QQ 邮箱"或"腾讯文档"（让它能把结果发给你或存到文档）
4. 自动化：设一个定时任务（每天 9 点自动跑）——看 WB-07
```

四件东西各司其职：

```text
专家   = "谁来干"
技能   = "用什么工具干"
连接器 = "干完结果送哪去"
自动化 = "什么时候自动干"
```

### 5.2 这套组合的产出

每天早上 9 点，你的企业微信或邮箱会收到一份：

```text
竞品动态简报 - 2026年8月6日

■ A 公司
  - 昨日发布新产品 X（来源：官网）
  - 融资消息（来源：36Kr）

■ B 公司
  - 高管变动（来源：脉脉）
  - 价格下调 10%（来源：竞品监控）

■ 老金的建议
  - 关注 A 公司新产品对我们 Q4 的冲击
  - B 公司降价可能引发价格战，建议提前备好应对话术
```

这份简报从前要你花 1 小时搜集整理，现在自动到你面前。这就是技能跟其他能力组合后的威力。

## 常见问题

**Q1：技能要钱吗？**
技能本身装是免费的，但**用技能会消耗积分**（因为 AI 要调用模型理解任务、执行动作）。有些高级技能标了价格，要单独买。新手先用免费的练手。

**Q2：装的技能越多越好吗？**
不是。同时启用太多技能会让 AI 困惑（不知道该调哪个），还可能误触发。老金建议同时启用 5-10 个最常用的，其他按需开关。

**Q3：技能和专家必须配合用吗？**
大多数技能可以单独用（在直接对话里调），但配合专家用效果更好。专家给身份，技能给工具，组合起来才像"专业人士 + 专业工具"。

**Q4：技能会过期失效吗？**
会。技能依赖的外部服务变了（比如某个网站改版了），技能可能失效。所以挑技能要看更新时间，长期不更新的别装。

**Q5：我能改已装技能的行为吗？**
部分能。在技能的"设置/权限"里可以配置它能访问什么、默认参数是什么。深度修改要懂技术（改技能包源码）。

**Q6：技能调用的数据安全吗？**
技能调用会经过 WorkBuddy 的授权机制，你能看到每个技能申请了什么权限。涉及敏感数据的技能（读邮件、读文件），先在测试任务里跑、确认行为可靠再用。企业版有更细的权限管控（看 WB-10）。

**Q7：技能市场有上万个技能，挑不过来怎么办？**
先按需求搜（"我想干 X"），看评分前 3-5 个的评论，挑评论多的、最近更新的。别贪多，先装 3 个常用的跑通，再加。
