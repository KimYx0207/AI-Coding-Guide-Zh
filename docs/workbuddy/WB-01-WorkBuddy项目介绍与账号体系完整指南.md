## 0. 一句话搞懂 WorkBuddy

老金在这篇里把 WorkBuddy 的定位讲透，因为后面所有教程都建立在"它到底是什么"这个地基上。

WorkBuddy 是腾讯云出品的 AI Agent 桌面工作站。你用一句话描述任务，多个 Agent 并行干活，直接产出 Word / Excel / PPT / 代码，而不是只给你一段聊天文本。

| 能力 | WorkBuddy 里的意义 |
|---|---|
| 一句话任务 | 用自然语言下需求，不用写代码或填表 |
| 多 Agent 并行 | 多个专员同时干子任务，缩短等待 |
| 本地文件操作 | 能读你电脑上的文件、操作你的应用 |
| 直接交付成品 | 产出 Word/Excel/PPT，不只是文字回复 |
| 深度研究 | 联网查资料、汇总、引用 |
| 数据分析 | 处理表格、出图、做汇报 |
| 计划任务 | 周期检查、定时汇报、后台监控 |
| Coding Mode | 内置编程模式，能跑命令、测试、起本地预览 |

一句话总结：**它不是聊天框，而是办公团队**。

## 1. WorkBuddy vs CodeBuddy：同账号、不同分工

腾讯这两个产品经常被混淆。老金用一张表把它们讲清楚：

| 维度 | WorkBuddy | CodeBuddy |
|---|---|---|
| **定位** | 办公 / 通用 Agent 桌面工作站 | 编程 Agent（IDE 插件 + 桌面） |
| **核心场景** | 写报告、做调研、出 PPT、跑自动化 | 写代码、补全、调试、重构 |
| **典型用户** | 上班族、管理者、运营、研究 | 开发者 |
| **出品** | 腾讯云 | 腾讯云（同一团队） |
| **账号体系** | **同一个腾讯账号** | **同一个腾讯账号** |
| **计费关系** | 订阅一边另一边通常可用（以官网为准） | 同上 |

> 💡 **关键记忆点**：**CodeBuddy 管开发，WorkBuddy 管办公**。同一个腾讯账号打通两边。具体计费、套餐互通规则以官网当前说明为准，不要把旧文档当成实时事实。

## 2. 能干什么、不能干什么

老金在这节把 WorkBuddy 的能力边界划清楚，因为新手最容易犯的错误是不清楚边界，要么低估它（把它当聊天框用），要么高估它（什么都敢交给它）。

### 2.1 它擅长干什么

```text
✅ 把一份散乱的素材整理成结构化文档（会议纪要、周报、调研）
✅ 联网查资料 + 汇总 + 引用，产出带来源的报告
✅ 处理表格数据，产出 Excel + 图表 + PPT
✅ 定时跑汇报（每天 / 每周）
✅ 在本地 demo 仓库里修小 bug、跑测试（Coding Mode）
✅ 从 WorkBuddy clone GitHub 仓库、发 PR
✅ 把产物推到企业微信 / QQ / 手机端
```

### 2.2 它不擅长或不该交给它的

```text
🚫 涉及敏感数据源的直接操作（凭证、生产数据库、客户隐私）
🚫 需要法律 / 财务最终判断的决策（AI 可以准备草稿，人来定）
🚫 高风险对发动作（发布公告、发付款、改生产）
🚫 把所有内部文档一次性塞给它当上下文（费用高、效果差、风险大）
🚫 在 WorkBuddy 里改生产仓库主干（用分支 + PR + Review）
```

> ⚠️ **注意**：能力边界会随版本变化。本节列的是 2026-08-06 的稳定口径，遇到新功能先在测试任务里验证，再决定要不要纳入日常工作流。

## 3. 账号体系：用哪个号、什么套餐

WorkBuddy 的账号和计费是新手最容易绕晕的地方。老金用三层讲清楚：

### 3.1 三层账号形态

| 形态 | 适合 | 关键特征 |
|---|---|---|
| **个人 Pro** | 个人用户、自由职业者 | 单账号、订阅制、与 CodeBuddy 个人版共享体系 |
| **企业 Team** | 团队、小公司 | 按席位计费、集中管理、共享集成 |
| **私有云企业版** | 大企业、强合规 | 私有部署、数据驻留可控、单价更高 |

### 3.2 计费关键事实（2026-08-06）

```text
- 个人 Pro：月费制，与 CodeBuddy 个人订阅共享账号体系。
- 企业 Team：按席位/月，价格随席位和套餐变。
- 私有云企业版：单价较高（2026-05-15 起有过价格调整，以 cloud.tencent.com 公告为准）。
```

> ⚠️ **注意**：**价格会变**。腾讯会调整套餐、上调或下调价格、改变免费额度。**任何具体数字以官网 workbuddy.ai / codebuddy.cn/work / cloud.tencent.com 当下显示为准**，不要把教程里的数字当成实时事实。

### 3.3 怎么选

```text
个人用 → 个人 Pro，先用订阅试一周
团队 5 人以内 → 企业 Team，按席位算清楚
大企业 + 合规要求 → 私有云企业版，找销售谈
不确定 → 先个人 Pro 跑通，再决定是否升级团队
```

## 4. 课堂工坊：用一句话让 WorkBuddy 总结一份 PDF

这个工坊让你第一次真实跑通 WorkBuddy。目标不是"体验一下"，而是让你确认：App 能登、Agent 能跑、Artifacts 能产出。建议拿一台日常办公电脑跟练，不要用生产环境做第一次实验。

### 4.1 工坊准备

你需要：

```text
- 一份本地 PDF 或 Word 文档（非敏感，比如一份公开报告或旧周报）
- 已登录的 WorkBuddy App（如果还没装，先去做 WB-02）
- 5 分钟时间
```

### 4.2 第一步：起一个新任务

在 WorkBuddy 桌面 App 的任务输入框，粘贴这段 Prompt（把方括号里的内容换成你的）：

```text
读这份本地文件：[把文件拖进任务输入框，或粘贴文件路径]
只做三件事：
1. 提炼 3 个核心观点
2. 抽出所有数字 / 数据，列成表格
3. 用一句话总结全文

不要改原文。不要联网。产出一份 Markdown 文档。
```

### 4.3 第二步：你应该看到什么

**你应该看到**：

```text
- 任务输入后，App 开始调度 Agent
- 界面显示"正在读取文件 / 正在分析 / 正在生成"
- 几秒到几十秒后，Artifacts 面板出现一份 Markdown 文档
- 文档包含：3 个观点、一张数据表、一句总结
```

**停下条件**：

```text
- 如果 App 提示"无法读取文件"：检查文件路径、格式、是否被其他程序锁定
- 如果长时间无响应（>2 分钟）：先取消任务，检查网络，再试一个更小的文件
- 如果产出明显错误（比如把表格数据张冠李戴）：不要直接信任，回到原文核对
```

### 4.4 第三步：核对产出

打开 Artifacts 里的 Markdown 文档，对照原文检查：

```text
- 3 个观点是否准确？
- 表格里的数字是否抄对？
- 一句总结是否没夸大？
```

> 💡 **老金提示**：AI 整理文档的常见错误不是"瞎编"，而是"漏信息"或"张冠李戴"。第一次跑一定要回原文核对，确认这条链路可靠后再加大任务量。

### 4.5 第四步：把产出存下来

在 Artifacts 面板里，把这份 Markdown 文档：

```text
- 复制到你的笔记（Notion / 飞书 / Obsidian）
- 或导出为 Word（如果 App 支持）
- 或贴到周报里
```

**工坊结束你应该留下的产物**：一份 AI 整理的文档 + 一份你手写的核对记录（哪些对了、哪些错了、下次怎么调 Prompt）。

## 5. 常见问题

### Q1：WorkBuddy 和 ChatGPT / Claude 有什么区别？

ChatGPT / Claude 主要是聊天助手，你问它答。WorkBuddy 是 Agent 工作站：你下任务，它调度多个 Agent 并行干活，直接产出 Word / Excel / PPT 等成品，还能操作本地文件、跑计划任务、连 IM 分发。**它不是聊天框，而是办公团队**。

### Q2：我已经有 CodeBuddy 订阅，还要单独买 WorkBuddy 吗？

CodeBuddy 和 WorkBuddy 是同账号同团队。订阅关系和套餐互通规则以官网当前说明为准，不要套用旧文档。最稳的做法：用现有腾讯账号登 WorkBuddy 试一下，看它给你的提示。

### Q3：WorkBuddy 会读我的私有数据吗？

它**能**读你主动交给它的本地文件，但具体数据驻留、日志、训练策略以官网隐私说明和企业版合约为准。涉及敏感数据时，先看 WB-09 企业安全章节，再决定交什么。

### Q4：个人 Pro 够用吗？

大多数人先用个人 Pro 跑通。等你需要多人共用账号、团队级集成、统一计费时再升级企业 Team。

### Q5：WorkBuddy 能完全替代我现在的办公软件吗？

不能。它擅长"整理、汇总、生成、自动化"，但不擅长需要最终判断的环节（法律、财务、对外发布）。把它当成"加速器"，不是"替代品"。

### Q6：我要不要等更成熟的版本再用？

任何 AI 工具都在快速迭代。**等"成熟版本"等于永远不用**。更稳的做法：先用一个真实小任务跑通（比如本篇工坊），确认它在你机器、你账号、你工作流里可靠，再决定扩大使用范围。
