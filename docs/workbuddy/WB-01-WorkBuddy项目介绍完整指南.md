## 开始之前：你要先准备什么

## 第一步：召唤一个 AI 专家，让它帮你写周报（15 分钟）

老金把这一步放在最前面，是因为看十遍功能介绍不如你自己召唤一个专家体会一次。这一步做完，你也就理解了 WorkBuddy 跟普通聊天 AI 的根本区别。

### 1.1 先理解"专家"是什么

WorkBuddy 里有个概念叫**专家**——简单说，就是给 AI 配一个具体职业身份，让它用那个职业的眼光干活。

举个例子：你把同一份销售数据扔给"通用 AI 助手"，它可能给你一堆正确的废话；扔给"销售分析专家"，它会按销售漏斗、转化率、客单价这些专业框架给你拆解。**差别在于角色身份**。

一个专家身上有三样东西（老金给你翻译成大白话）：

- **人设**：它是谁（财务专家、营销专家、写作专家）
- **方法论**：它怎么思考（财务专家看数据先看异常，营销专家看转化先看漏斗）
- **工具链**：它能调什么（写作专家能调文档生成，数据专家能调表格计算）

### 1.2 怎么召唤

打开 WorkBuddy 桌面 App，找到界面上的**专家**入口（通常在左侧栏，可能叫"专家中心"或"专家"——以你本机 App 显示为准）。点进去后，你会看到一个按行业分类的专家列表，每个专家都有一张卡片，写着：

- 这位专家**擅长什么**
- 它**能帮你做**哪些事
- **使用示例**（给你参考怎么提问）

老金建议你第一次选一个简单实用的——比如"办公写作专家"或"会议纪要专家"。找到合适的卡片后，点上面的**召唤**按钮（可能叫"召唤专家"或"开始对话"），就进入对话界面了。

### 1.3 把任务交给它

进入对话界面后，把下面这段话复制粘贴进去（方括号里的内容换成你自己的）：

```text
我是 [你的岗位，比如运营/产品/行政]，这周主要做了三件事：
1. [事项一，一句话说清]
2. [事项二，一句话说清]
3. [事项三，一句话说清]
下周计划：[一两个计划]

帮我把这些整理成一份可以直接发给领导的周报：
- 标题、本周进展、下周计划、需要协调的问题，四块结构
- 语气专业，不啰嗦
- 控制在 300 字以内
```

### 1.4 你会看到什么

发出去之后，几秒到几十秒内，这位专家会用它职业身份的语气给你回复一份完整周报。你应该看到的是：

```text
- 标题：本周工作总结 - [你的岗位] - [日期]
- 本周进展：三条按重要性排好序的工作，措辞专业
- 下周计划：你写的计划被润色过，显得更清晰
- 需要协调的问题：如果原话里没写，它会留一个占位符提醒你补
```

这份周报你可以直接复制粘贴到企业微信、邮件、飞书文档里发出去。

### 1.5 如果卡住了怎么办

老金把第一次可能踩的坑列出来，你照着排查：

```text
❌ 没看到"专家"入口
   → 可能你登的是极简版界面。检查 App 是否完整启动，或看左侧栏是否折叠了

❌ 召唤了但回复跟普通 AI 一样，没专业感
   → 确认你是不是真的点了"召唤专家"进对话，而不是进了普通对话框
   → 换个更贴合任务的专家（比如写代码的事别找写作专家）

❌ 提示"积分不足"
   → 专家会消耗积分（下面第三步会详细讲积分）。先看你的积分余额，
     或换个更轻量的任务

❌ 产出明显跑偏
   → 大概率是任务描述太模糊。把"帮写周报"改成"帮我把这三件事整理成 300 字周报"
```

### 1.6 这一步你体会到了什么

如果你以前用过 ChatGPT、文心一言、通义千问这类聊天 AI，你会感觉到一个明显差别：**那些工具像在一个什么都会但什么都不精的实习生面前说话，WorkBuddy 的专家像一个真有那个职业身份的人在干活**。

这就是 WorkBuddy 第一个核心价值——**角色化**。你不需要自己写很长的提示词去定义"你是一位资深财务专家，请按以下方法分析..."，这些都已经预置在专家卡片里，点一下"召唤"就用。

## 第二步：看一眼专家团，理解"多角色协同"（5 分钟）

这一步老金不让你真跑，原因是**专家团消耗的积分是单专家的 3 到 5 倍**，第一次试用别浪费积分，先把机制看懂就行。

### 2.1 什么是专家团

**专家团**就是多个专家分工协作，一起干一件复杂的事。它有一个**团长**（也是一个 AI 角色，相当于项目经理），你只要把任务告诉团长，团长会自动：

```text
1. 把你的任务拆成几个子任务
2. 分配给最合适的几个专家
3. 这些专家并行（同时）干活
4. 团长把所有人的产出合并成一份完整成果
5. 返回给你
```

举个例子：你让单专家做"竞品分析报告"，营销专家只能干营销那一块。但你让**专家团**做，团长会自动让市场专家查市场份额、财务专家比财报数据、设计专家出 PPT 模板，最后给你一份完整的竞品分析 PPT。

### 2.2 怎么找到专家团

回到**专家中心**（刚才召唤单专家的地方），切换到**专家团**分类。你会看到专家团卡片，上面写着：能力介绍、擅长领域、团队成员（这个团里有哪几个专家）、任务示例。

老金建议你浏览几张卡片，找一个跟你工作相关的场景读一读任务示例，你就明白什么情况下值得用专家团了。

### 2.3 什么时候该用专家团

```text
✅ 值得用（积分花得值）：
   - 复杂任务，单一岗位干不完（竞品分析、市场调研、大型汇报）
   - 一次要出多种形态的成果（Word 报告 + Excel 数据 + PPT 汇报）
   - 重要任务，值得花 3-5 倍积分换端到端交付

🚫 不值得用（白烧积分）：
   - 简单任务（写封邮件、整理个表格、改个文档）→ 用单专家甚至直接对话就够
   - 第一次试用 → 先把单专家跑熟，再来碰专家团
   - 积分紧张时 → 专家团会很快烧光配额
```

### 2.4 进阶玩法：自建专属专家团

广场上现成的专家团不够用时，你可以**自己建一个专属专家团**。WorkBuddy 有交互式引导，你只要跟它说"我想组建一个做 [某件事] 的专家团，成员要有 [角色 A、角色 B、角色 C]"，它会帮你把团搭起来。这部分老金放在 WB-03 详细讲。

### 2.5 这一步你体会到了什么

如果你看过老金写的 Claude Code 或 Codex 教程，会知道那两个工具也有多 Agent（多个 AI 一起干活）的能力。但**它们的多 Agent 是要你自己拼装、写配置文件的**——你得定义每个 Agent 的身份、它们怎么通讯、谁先干谁后干。

WorkBuddy 的专家团是**预组好的**——你点一下"召唤"就并行干活，团长自动拆解分配。这是"开箱即用"和"深度可控"的差别，没有优劣，看你要哪种。

## 第三步：搞清账号、积分和价格（别踩坑）

老金把这部分放在第三步，是因为前两步你已经在烧积分了，必须让你心里有数。这一节信息量大，但都是掏钱决策的关键，耐心看完。

### 3.1 WorkBuddy 的多端形态

WorkBuddy 不是只有一个桌面 App，它是一套**多端产品**：

```text
- 桌面 App（Windows / macOS）：主力工作台，功能最全
- 微信 / 企业微信：远程触发、接收推送、跨端接力
- 微信小程序：手机上继续任务、快速查看
```

同一个微信账号打通所有端——你在桌面开了一个任务，出门了用手机小程序接着看，回到家用企业微信推送给同事，全程不断档。

### 3.2 WorkBuddy 和 CodeBuddy 的关系

腾讯这两个产品经常被搞混，老金一句话讲透：

```text
CodeBuddy = 管写代码（编程助手，类似 Cursor、GitHub Copilot）
WorkBuddy = 管办公（AI 员工，帮你出文档/报表/调研/汇报）
```

**同一个账号、积分共享**——你订一份，两个产品都能用。所以不要纠结"我该订哪个"，订了就都能体验。

### 3.3 积分是什么、怎么扣

WorkBuddy 不按"次数"计费，而是按**积分**计费。积分你可以理解成"AI 干活的能量额度"，类似游戏里的钻石：

- 你每月有一批积分额度（按订阅套餐给）
- 每次召唤专家、用技能、跑专家团，都扣积分
- 不同模型、不同复杂度的任务扣的积分不一样（旗舰模型扣得多，专家团是单专家的 3-5 倍）
- 积分用完了任务就跑不动，要么等下个月、要么加购

**积分消耗优先级**（先扣哪个）：先用免费体验额度，再按到期顺序扣赠送积分，最后扣付费积分。

### 3.4 价格大概多少（2026 年 8 月的框架）

老金把当前的价格框架列给你，但**先念三遍免责**：**AI 产品调价频繁，下面是 2026 年 8 月的框架，你下单前一定要打开 App 或官网核对当前价格，别照着老金写的数字掏钱**。

个人版（按月或按年付）：

```text
- 免费版：0 元，有限免费积分额度（够你体验几轮）
- 专业版：约 99 元/月（年付通常有优惠），积分额度大幅提升
- 年度版：约 119 元/年起（按年付折算更便宜）
```

企业版（按人头/月）：

```text
- SaaS 企业版：约 199 元/人/月，企业统一管理、共享集成
- 专有云企业版：约 316 元/人/月（2026 年 5 月 15 日刚从 158 元调上来），
  支持私有部署、数据驻留可控，适合强合规需求的大企业
```

**怎么选**：

```text
- 个人尝鲜 → 免费版跑通，再决定要不要升专业版
- 个人重度使用 → 专业版月付试一个月，顺手了转年付
- 小团队（5-20 人）→ SaaS 企业版，按席位算清楚
- 大企业 + 合规要求 → 专有云企业版，找腾讯销售谈
```

### 3.5 查看你的积分余额

老金建议你登录后**第一件事**就是找到积分余额在哪看——通常在 App 的"我的"、"账户"或"设置"里（以你本机为准）。**第一次试用优先用免费体验额度**，摸清消耗速率，再决定要不要付费。

## 第四步：判断你是不是 WorkBuddy 的目标用户

老金在这一步把"该不该用 WorkBuddy"的边界划清楚，因为选错工具比不选工具更糟。

### 4.1 WorkBuddy 适合你，如果

```text
✅ 会用 Word / Excel / 企业微信，但不会命令行
✅ 想用 AI 办公，但被各种 AI 工具的英文界面、API 配置劝退过
✅ 团队在国内，主要沟通是企业微信 / 微信 / QQ
✅ 不想折腾代理、海外信用卡、英文文档
✅ 想要下载就能用、像用微信一样简单的 AI 助手
✅ 是开发者，但身边有非技术同事、家人需要 AI 工具
✅ 想给团队部署一个低门槛、中文友好、贴合国内生态的 AI 办公工具
```

### 4.2 别选 WorkBuddy，如果

```text
❌ 你要做大型代码库重构、复杂架构设计 → 用 Claude Code（本仓库有教程）
❌ 你要命令行、API、多入口（CLI+Web+Cloud）深度协作 → 用 Codex
❌ 你要写 Hooks、Subagent、Agent SDK 做自动化定制 → 用 Claude Code
❌ 你要完全本地部署、零云依赖 → 用 OpenClaw
❌ 你团队在海外、主要用 Slack / Notion / Stripe → 用 Codex 或 Claude Code
```

### 4.3 WorkBuddy 现在的缺点（不吹不黑）

老金也把多源实测印证的缺点告诉你，免得你期望落差：

```text
⚠️ 自定义能力相对较弱：不像 Claude Code 那样能精细控制每一步
⚠️ 专家团的积分消耗较高：复杂任务烧积分快，免费额度很快用完
⚠️ 偏办公场景：写代码能力虽然有（Coding Mode），但比不上专业编程工具
⚠️ 生态绑定腾讯系：深度集成企业微信/腾讯文档是优势，但也意味着换生态成本高
```

如果你能接受这些缺点，WorkBuddy 就是你的菜。

## 第五步：跟其他 AI 工具的差别（一表说清）

老金把这一节做得尽量短——详细对比留给 WB-10，这里只给你一个快速决策参考。

| 维度 | Claude Code / Codex | WorkBuddy |
|---|---|---|
| **给谁用** | 开发者 | 办公人、普通人、国内团队 |
| **形态** | 命令行、多入口分层 | 桌面 App + 微信 + 小程序 |
| **怎么登** | API Key（AI 服务的使用凭证，类似账号密码）、海外账号 | 微信扫码 |
| **角色化** | 自己写 Agent 配置 | 专家卡片，点一下"召唤" |
| **多 AI 协作** | 自己拼、写配置 | 专家团，团长自动拆解 |
| **能力扩展** | Skills / MCP（技术向） | 技能市场一键装 |
| **生态** | GitHub / Slack / Discord（海外） | 企业微信 / 腾讯文档 / QQ 邮箱（国内） |
| **语言** | 英文为主 | 全中文 |
| **网络** | 部分用户要代理 | 国内直连 |
| **支付** | 海外信用卡 | 微信 / 支付宝 |

一句话总结：**Claude Code / Codex 是深度可控的专业工具，WorkBuddy 是开箱即用的办公助手，两者解决的不是同一个问题，可以共存**。老金自己写代码用 Claude Code，写周报、做调研、出汇报用 WorkBuddy——根据任务选工具，不二选一。

## 常见问题

**Q1：WorkBuddy 能完全替代 ChatGPT / Claude 吗？**
不能完全替代。ChatGPT、Claude 这类聊天工具适合"你问我答"的开放对话；WorkBuddy 适合"下任务、出成品"的办公场景。两者侧重不同，可以共存。

**Q2：我已经订了 ChatGPT Plus / Claude Pro，还要订 WorkBuddy 吗？**
看场景。如果你只用得到聊天问答，那些工具够用。如果你有大量办公出活需求（周报、调研、PPT、企业微信分发），或者要给非技术同事、国内团队一个 AI 工具，WorkBuddy 互补。

**Q3：专家团消耗积分那么高，值得用吗？**
复杂任务值得（一次出多种形态成果、端到端交付），简单任务不值得（单专家甚至直接对话就够）。第一次试用别用专家团，先把单专家跑熟。

**Q4：WorkBuddy 真的不用翻墙吗？**
国内服务器直连，正常办公网络不用翻墙。具体网络环境以你本机实测为准——少数企业内网可能有自己的出口策略，跟 WorkBuddy 本身无关。

**Q5：腾讯生态接了哪些？**
目前接通的有 QQ 邮箱、腾讯文档、腾讯乐享、腾讯会议、TAPD（腾讯的项目管理工具），企业微信有稳定接入，还能自己加自定义连接器。具体怎么接看 WB-05。

**Q6：我要给团队部署，怎么算账号？**
看 WB-10。团队场景按席位计费、集中管理，企业版还能私有部署。

**Q7：AI 会不会读我的隐私数据？**
专家本身不会主动读取系统权限，只处理你主动交给它的对话和文件。但接了连接器、知识库之后，它能访问的数据范围会扩大——涉及敏感数据时，看 WB-10 的安全章节再决定交什么。
