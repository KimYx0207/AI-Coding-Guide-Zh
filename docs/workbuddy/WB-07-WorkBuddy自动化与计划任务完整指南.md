# WB-07 WorkBuddy 自动化与计划任务：让 AI 定时和远程干活

老金写这篇教程的目的——让你学会用**自动化**把重复活交出去。学完这篇，你的 WorkBuddy 就能每天定时出汇报、监控到异常自动通知你、你在微信里一句话就能远程触发它干活——你睡觉它干活，你下班它接着干。

这是把 WorkBuddy 从"你点一下它干一下"升级到"7×24 小时自动运转"的关键能力。

## 先搞清：自动化是什么、有哪几种

WorkBuddy 的**自动化**有三种典型形态，老金先给你认认脸：

```text
1. 定时任务：到点就跑（每天 9 点出汇报、每周一 10 点出周报）
2. 触发任务：事件触发就跑（收到特定邮件、群里 @ 它、文件更新）
3. 远程任务：你在微信/企业微信里远程让它干活
```

三种可以组合——比如"每天 9 点查邮件，发现紧急的立刻推送到企业微信"。

**自动化的核心价值**：

```text
✅ 解放重复劳动（每天必做的汇总、监控、汇报）
✅ 跨时段工作（你下班它继续干、你睡觉它守夜）
✅ 跨设备触发（手机一句话，桌面端开始干活）
✅ 闭环交付（任务跑完自动通知你，不用盯着）
```

**老金的提醒**：自动化是双刃剑。它能解放你，也能在配错时持续浪费积分、误发消息、误删数据。所以这篇老金会重点讲**怎么配得安全**。

准备清单：

```text
✅ WB-04~06 都学完，会用技能/连接器/知识库（自动化要组合它们）
✅ 想清楚一件你天天干的重复活（汇报、监控、提醒都行）
✅ 账号有积分（自动化会持续消耗，留意余额）
✅ 设过积分预警（剩 10% 时停下来）
```

## 第一步：建你的第一个定时任务（15 分钟）

老金带你建一个所有人都能用上的——**每天早上 9 点自动生成"昨日工作摘要"**。

### 1.1 找到自动化入口

主界面找**自动化**、**定时任务**或**工作流**入口（不同版本叫法不同，认准"自动化""定时""工作流"这几个关键词）。点进去你会看到所有已建的自动化列表。

### 1.2 新建定时任务

点**新建**或**创建自动化**，选**定时触发**类型：

```text
第一步：选触发方式
   → 定时触发 → 每天上午 9:00

第二步：选执行内容
   → 召唤办公写作专家
   → 基于我的"工作日志"知识库
   → 总结昨天的事项，生成一份"昨日工作摘要"
   → 包含：完成的事、未完成的事、今天要优先处理的

第三步：选输出方式
   → 推送到我的企业微信 / QQ 邮箱（用连接器）
   → 同时存一份到腾讯文档（建一个"每日摘要"文档）

第四步：命名和保存
   → 任务名：每日 9 点昨日工作摘要
   → 启用状态：开
   → 保存
```

### 1.3 第一次跑前的预演

任务保存后，**别等明天 9 点**，先手动跑一次验证：

```text
在自动化列表找到这个任务，点"立即运行"或"测试运行"。
```

观察整个流程跑通没：

```text
✅ 它能不能读到你的工作日志（知识库检索成功）
✅ 它能不能生成摘要（专家产出正常）
✅ 它能不能推送到企业微信/邮箱（连接器调用成功）
✅ 它能不能存到腾讯文档（写权限正常）
```

任何一步失败，看错误提示修。

### 1.4 等到明天 9 点看效果

预演跑通后，等明天 9 点（或你设的触发时间），看你的企业微信/邮箱是不是真的自动收到了摘要。

```text
如果收到 → 恭喜，你的第一个定时任务上线了
如果没收到 → 看下面排查
```

### 1.5 卡住了怎么办

```text
❌ 任务没在指定时间跑
   → 检查时区设置（默认东八区，别选错）
   → 检查任务是不是"已启用"状态
   → 检查电脑/App 是不是在那时间开着（部分自动化要 App 在线）
   → 看任务日志，是不是跑了但失败了

❌ 跑了但推送没收到
   → 检查连接器是不是还连着（断开了就推不出）
   → 检查推送目标对不对（企业微信 vs 个人微信）
   → 检查通知权限（手机/电脑是不是禁了 WorkBuddy 通知）

❌ 跑了但产出是空的 / 错的
   → 知识库检索没找到东西（资料范围或问法要调）
   → 专家任务描述太模糊（任务模板要写更具体）
   → 连接器读不到数据（邮箱空、文档没内容）
```

## 第二步：事件触发任务

### 2.1 什么是事件触发

跟"到点就跑"不同，事件触发是**"某件事发生了才跑"**。典型场景：

```text
- 收到带"紧急"关键词的邮件 → 立刻通知我
- 群里有人 @ 我和 WorkBuddy → 自动处理那个问题
- 某份腾讯文档被修改了 → 自动生成变更摘要
- 监控到某支股票跌破阈值 → 立刻推送提醒
```

### 2.2 建一个邮件触发任务

老金带你建一个：**收到带"紧急"关键词的邮件，立刻推送到企业微信**。

```text
第一步：选触发方式
   → 连接器触发 → QQ 邮箱 → 新邮件到达
   → 过滤条件：标题或正文含"紧急"

第二步：选执行内容
   → 召唤办公写作专家
   → 总结这封邮件的核心诉求、需要我做啥、最晚什么时候回复
   → 控制在 100 字以内

第三步：选输出方式
   → 立刻推送到企业微信（高优先级通知）

第四步：保存启用
```

### 2.3 你会看到什么效果

下次有人给你发"紧急"邮件，几秒内你的企业微信会弹一条：

```text
🚨 紧急邮件提醒

发件人：[某人]
主题：[邮件标题]
核心诉求：[一句话]
你要做：[具体动作]
建议回复时间：[今天下班前 / 立刻]

回复"详情"看完整邮件内容。
```

你不用时刻盯着邮箱，重要的事主动找你。

### 2.4 事件触发的注意点

```text
⚠️ 触发条件别设太宽（"所有邮件都通知"会刷屏）
⚠️ 触发条件别设太窄（关键词选太偏会漏掉该通知的）
⚠️ 高频事件要限流（同一类事件一分钟最多触发几次）
⚠️ 误触发要有"关闭"开关（出问题时能立刻停）
```

## 第三步：远程触发——微信里让桌面干活

### 3.1 这是什么

你在手机微信/企业微信里给 WorkBuddy 发一句话，它能触发桌面端的复杂任务。比如：

```text
- 通勤路上发"生成今天的会议准备清单" → 桌面端开始干
- 出差时发"整理一下这个客户的资料发给我" → 桌面端跑完推回你手机
- 半夜突然想到件事发"明天提醒我联系 XX" → 加进待办
```

### 3.2 怎么用

前提：你已经接通了企业微信或微信的连接器（看 WB-05）。

```text
第一步：在微信/企业微信里找到 WorkBuddy 的小程序或对话入口
第二步：像跟同事说话一样发指令
第三步：WorkBuddy 桌面端（如果开着）会接到任务开始执行
第四步：跑完结果推回你的微信
```

### 3.3 实战：通勤路上准备早会

```text
你在地铁上，9 点要开早会。
打开企业微信给 WorkBuddy 发：
  "9 点要开部门早会，基于我昨天的工作日志，
   准备一份 3 分钟的发言稿，重点说我昨天的进展和今天的计划。
   推到我的企业微信，我等下到公司就能直接念。"

10 分钟后你到公司，企业微信已经收到了一份发言稿。
```

这就是远程触发的威力——把碎片时间利用起来。

### 3.4 远程触发的限制

```text
⚠️ 桌面端 App 通常要在线（关机/睡眠状态下任务可能跑不了）
⚠️ 远程任务消耗积分（手机指令也算一次完整任务）
⚠️ 涉及大文件的远程任务会慢（建议小任务用）
⚠️ 多人共用账号时远程触发要协调（别互相覆盖任务）
```

## 第四步：自动化任务的管理和监控

老金这一步讲怎么管你已经建的自动化，避免它们在后台乱跑。

### 4.1 任务面板

进入自动化入口，你看到所有任务列表。每个任务卡片通常显示：

```text
- 任务名 + 启用/禁用开关
- 上次运行时间 + 状态（成功/失败）
- 累计运行次数 + 消耗积分
- 最近一次的产出预览
```

### 4.2 日常监控

老金建议你**每周检查一次**：

```text
✅ 哪些任务这周跑过、成功没
✅ 失败的任务是什么原因（看日志）
✅ 消耗积分是否异常（突然变多可能配错了）
✅ 还需要的任务继续开，不需要的关掉
```

### 4.3 任务的暂停、修改、删除

```text
- 暂时不用 → 点"禁用"（保留配置，下次再开）
- 配置要改 → 点"编辑"（改触发条件、执行内容、输出方式）
- 彻底不用 → 点"删除"（清理掉，避免堆积）
```

### 4.4 任务失败通知

建议**给关键任务配"失败通知"**——任务跑失败时主动推送到你的微信/邮箱，你立刻知道。不然任务静默失败好几天你都不知道。

## 第五步：自动化的安全和防坑

老金这一步是为你好——自动化配错可能造成持续浪费或事故。

### 5.1 积分失控防护

```text
✅ 设积分预警：剩余 10% 时暂停所有自动化
✅ 设单任务限额：每个任务每天最多消耗 X 积分
✅ 高消耗任务优先级降：非紧急的别用专家团
✅ 定期看积分报表：找出"烧钱大户"重新优化
```

### 5.2 误操作防护

```text
🚫 自动化任务里别配"删除"动作（除非绝对必要）
🚫 别配"自动回复邮件/消息"（容易误发，至少要人审一遍）
🚫 别配"修改生产文档/代码"（自动改的风险大）
✅ 高风险动作改成"草稿模式"：跑完产出草稿，人审后再发
```

### 5.3 出事了怎么办

```text
🚨 自动化误发了消息 / 误删了文件
   → 立刻"禁用"那个任务（点开关，几秒生效）
   → 撤回/恢复（消息撤回、文件从回收站恢复、文档版本回滚）
   → 检查任务配置，找出是哪一步错了
   → 修好后先"测试运行"，确认正常再正式启用
```

### 5.4 团队自动化的协作

```text
- 共享自动化：建好的任务可以分享给同事（生成分享码）
- 任务 owner：每个任务明确"谁负责"，避免出问题互相推
- 审批机制：高风险任务（外发、批量）要设置团队审批
- 不重叠：团队里别多人建相同任务（重复跑浪费积分）
```

## 常见问题

**Q1：自动化任务要电脑一直开机吗？**
看实现方式。**云端自动化**（基于连接器和云端服务）不用开机，到点云上跑。**本地自动化**（涉及本地文件、桌面操作）通常要 App 在线。混合任务看具体环节，建议保持 App 后台运行。

**Q2：自动化消耗积分快吗？**
看任务复杂度。简单的定时通知消耗少，复杂的专家团 + 多连接器任务消耗大。建议先用低成本任务试，看一周消耗多少，再决定是否扩。

**Q3：任务失败了会自动重试吗？**
通常会重试几次（看任务配置）。重试还失败就停掉，等你人工处理。所以"失败通知"很重要，不然任务静默失败好几天你不知道。

**Q4：能同时跑多个自动化任务吗？**
能。但同时跑太多会拖慢、可能冲突。建议错开高峰（别所有任务都设 9 点），同一个资源的任务别重叠（都在改同一份文档会冲突）。

**Q5：自动化任务能分享给同事吗？**
能。生成分享码或链接，同事导入就能用。但**任务里引用的资源（知识库、连接器）同事也要有权限**，不然导入了跑不动。

**Q6：远程触发算谁的积分？**
算触发者的。你远程触发，扣你的积分。团队共用账号时要协调，避免个人积分被团队任务烧光。

**Q7：自动化任务会被公司审计吗？**
企业版下，管理员通常能看到你建了什么任务、消耗多少积分、调用什么数据。涉及公司数据的任务要符合公司政策，别私建涉及客户/财务的自动化。
