WorkBuddy 这条主线的所有教程，都是为**会用电脑但不会命令行**的读者写的——办公族、管理者、运营、学生、研究者，以及开发者身边那些"不是程序员但想用 AI"的家人同事。

## WorkBuddy 的五个核心概念（30 秒版）

这套教程全部围绕这五个概念展开。先记住它们，后面每篇教程都是教你怎么把其中一个用起来：

| 概念 | 一句话 | 类比 |
|---|---|---|
| **专家** | 给 AI 配一个领域角色（人设 + 方法论 + 工具链），比如财务专家、营销专家 | 雇一个专员 |
| **专家团** | 多个专家分工协作，团长自动拆解任务、并行执行、完整交付 | 雇一个项目组 |
| **技能（Skill）** | 让 AI 能做某个具体动作（发邮件、查股价、读写文件），从技能市场一键安装 | 给员工工具 |
| **自动化** | 定时跑任务、跨应用流转、远程用 IM 触发、7×24 小时连续运转 | 员工自动排班 |
| **连接器** | 把 WorkBuddy 接到腾讯生态（QQ 邮箱、腾讯文档、腾讯乐享、腾讯会议、TAPD） | 员工的外联通讯录 |

它们的关系（官方原话）：

```text
Skill     = 能力
专家      = 能力 + 角色人设 + 方法论
专家团    = 多专家协同的完整执行体
```

## 三条阅读路线

```text
🚀 想最快用起来（30 分钟）：
WB-01 → WB-02 → WB-03 召唤第一个专家 → 你已经能出活了

💼 办公日常（2-3 小时）：
WB-01 → WB-02 → WB-03 专家 → WB-04 技能 → WB-05 连接器 → WB-06 自动化

🔒 团队部署（半天）：
WB-01 → WB-02 → WB-09 企业安全 → WB-03~WB-06 五大概念 → WB-07 多端
```

**开发者**：WB-01 → WB-08 Coding Mode → WB-10 对比（判断什么时候用 WorkBuddy、什么时候切回 Claude Code/Codex）。

## 卡住时按症状反查

```text
不知道 WorkBuddy 是什么 → WB-01
装不上 / 登不进 → WB-02
想让 AI 以专业角色干活 → WB-03 专家
想让 AI 会发邮件/查股价/读写文件 → WB-04 技能
想接 QQ 邮箱/腾讯文档/腾讯会议 → WB-05 连接器
想让 AI 定时跑或远程触发 → WB-06 自动化
想手机/企业微信继续桌面任务 → WB-07 多端
想写代码 → WB-08 Coding Mode
担心积分/席位/数据安全 → WB-09 企业安全
纠结用哪个 AI 工具 → WB-10 对比
```
