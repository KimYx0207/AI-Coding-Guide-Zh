## 这份文档是写给谁的

老金把 WorkBuddy 这条主线全部写给一类人——**会用电脑但不会命令行**的普通人：办公族、管理者、运营、学生、研究者，以及开发者身边那些"不是程序员但想用 AI"的家人同事。

如果你要找的是给开发者的命令行深度工具，请去本仓库的 [Claude Code 系列](../claude-code/01-Claude-Code完整安装指南.md) 或 [Codex 系列](../codex/CX-01-Codex-App安装与认证完整指南.md)，那才是开发者的主场。WorkBuddy 不是为了替代它们，而是为了补上"普通人也要用 AI"这一块。

## WorkBuddy 到底是什么（30 秒版）

一句话：**腾讯做的、给中国人用的、像请了一群 AI 员工帮你办公的桌面助手**。

你下载一个 App，用微信扫码登录，然后用大白话告诉它"帮我把这份资料整理成周报"，它就能真的给你产出一份 Word 文档。不需要写代码、不需要配 API Key（API Key 就是 AI 服务的使用凭证，类似账号密码）、不需要英文、不需要翻墙。

本系列重点练习的是文件处理和办公成果：把材料交给 WorkBuddy，查看过程，对照原文检查结果，再继续修改。专家、技能和连接器分别帮助你组织方法、复用流程和访问资料。

## 五个核心概念（需要时查）

遇到不熟悉的词，可以回来查这张表；第一份周报不要求先记住全部概念：

| 概念 | 通俗解释 | 类比 |
|---|---|---|
| **专家** | 给 AI 配一个具体职业身份（比如财务、营销、写作），让它用那个职业的专业眼光干活。一个专家 = 一个能力 + 一套经验 + 一套工具 | 雇一个专员 |
| **专家团** | 一个任务派给好几个专家分工干，团长（也就是调度员角色的 AI）自动把任务拆开、分配、并行执行、最后合并成完整成果 | 雇一个项目组 |
| **技能（Skill）** | 把某类任务的方法、说明和必要工具组织成可复用能力，可安装现成技能，也可按需导入或创建 | 给员工配方法与工具 |
| **定时任务** | 按时间规则重复执行，比如每天 9 点生成汇报；手机远程发指令另用已绑定的助理 | 员工按计划排班 |
| **连接器** | 把 WorkBuddy 接到腾讯全家桶（QQ 邮箱、腾讯文档、腾讯会议、企业微信、腾讯乐享、TAPD 项目管理），让 AI 能直接读你的邮件、改你的文档 | 员工的外联通讯录 |

它们的关系，老金用一个递进的逻辑讲清楚：

```text
技能        = AI 能做的具体动作（能力）
专家        = 能力 + 职业身份 + 经验（角色化）
专家团      = 多个专家协同干一件复杂事（团队化）
连接器      = 让上面这些能伸进你的腾讯办公软件（生态化）
定时任务    = 按时间规则重复执行
远程助理    = 通过已绑定的手机通道发指令，让在线电脑处理任务
```

先分清这几项能力，遇到具体任务时再组合使用。定时任务负责按计划执行，远程助理负责接收手机指令，两者分别配置。

## 三条阅读路线

```text
🚀 第一次用：
WB-02 安装登录 → WB-01 周报练习 → 自己修改一处事实，再保存草稿

💼 办公日常（2-3 小时）：
WB-01 周报 → WB-03 表格 → WB-06 资料问答；需要复用时再学 WB-04 / WB-07

🔒 团队部署（半天）：
WB-01 → WB-02 → WB-10 企业账号与安全 → WB-03~WB-07 五大概念 → WB-08 多端
```

**开发者**：WB-01 → WB-09 Coding Mode → WB-10 对比（判断什么时候用 WorkBuddy、什么时候切回 Claude Code/Codex）。

## 一个原则

**WorkBuddy 的卖点是简单，所以这套教程也尽量简单**——每篇只解决一类问题、带一个能跑通的任务、留一样能带走的成果。如果你看某篇觉得"好绕、好复杂"，那是老金写得不对，不是工具的问题，欢迎到公众号"老金带你玩AI"反馈，我改。
