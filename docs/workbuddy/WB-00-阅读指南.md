## 这份文档是写给谁的

WorkBuddy 这条主线的所有教程，都是为**会用电脑但不会命令行**的读者准备的——办公族、管理者、运营、学生、研究者，以及开发者身边那些"不是程序员但想用 AI"的家人同事。

如果你找的是**给开发者的深度 CLI 工具**，请去看本仓库的 [Claude Code 系列](../claude-code/01-Claude-Code完整安装指南.md) 或 [Codex 系列](../codex/CX-01-Codex-App安装与认证完整指南.md)。这两条主线才是开发者的主场。

> **2026-08-06 版本口径**：WorkBuddy 是腾讯云出品的 AI 办公助手桌面 App，与 CodeBuddy 同团队同账号。本系列按 2026-08-06 可查官方资料修订；WorkBuddy 没有 semver，菜单名、价格、套餐一律以本机 App 关于页和官网（workbuddy.ai / codebuddy.cn/work）为准。

## WorkBuddy 的核心卖点（30 秒版）

```text
1. 更简单：下载 App、微信扫码、打字就能用——不用 CLI、不用 API Key、不用代理
2. 更中国：国内服务器、企业微信/微信/QQ 原生集成、人民币支付、中文优化
```

详细对比看 [WB-01 项目介绍](WB-01-WorkBuddy项目介绍与账号体系完整指南.md)。

## 术语表（先看这个）

| 术语 | 一句话解释 |
|------|-----------|
| **WorkBuddy** | 腾讯云出品的 AI 办公助手桌面 App |
| **CodeBuddy** | 腾讯云的编程 Agent，与 WorkBuddy 同账号同团队 |
| **任务** | 你用一句话描述给 WorkBuddy 的一件事 |
| **Artifacts** | 任务产出的可复用物件（Word/Excel/PPT/代码） |
| **Coding Mode** | WorkBuddy 内置的编程模式（办公场景偶尔写点代码用） |
| **集成** | 与企业微信 / 微信 / QQ / GitHub 等外部系统的连接 |
| **计划任务** | 周期或定时触发的自动化任务 |
| **审批** | 高风险动作执行前需要人确认的环节 |

## 三条阅读路线

```text
🚀 想最快用起来（30 分钟）：
WB-01 → WB-02 → WB-03 的工坊 → 你已经能出活了

💼 办公日常（2-3 小时）：
WB-01 → WB-02 → WB-03 → WB-04 → WB-07 → WB-08

🔒 团队部署（半天）：
WB-01 → WB-02 → WB-03 → WB-09 → WB-07 → WB-08
```

**开发者**：WB-01 → WB-05 → WB-06 → WB-10（判断什么时候用 WorkBuddy、什么时候切回 Claude Code/Codex）。

## 一句话原则

**WorkBuddy 的卖点是简单，所以这套教程也尽量简单**——每篇只解决一类问题、给一个可跑的工坊、留一样能带走的产物。如果你看某篇觉得"好复杂、好绕"，那是教程写得不对，不是工具的问题，欢迎反馈。
