## 先搞清：连接器是什么、跟技能啥区别

老金这一节讲清楚两个容易混的概念。

**连接器**（Connector）= 把 WorkBuddy 接到外部软件的桥梁，让 AI 能直接读写那个软件里的数据。它是技能的一种特殊形态——专门用来对接外部服务的。

打个比方：

```text
技能     = AI 手里的小工具（网页搜索、文件读写这种通用动作）
连接器   = 专门对接某个具体软件的桥（QQ 邮箱连接器、腾讯文档连接器）
```

**连接器比普通技能更深**——它不只是调用接口，还做了身份授权、数据格式适配、稳定连接（长链接），所以连接器接进来的软件，AI 能像操作自家功能一样操作它。

**WorkBuddy 目前接通的腾讯生态**（老金按 2026 年 8 月的实际情况列，新连接器会持续上线，以你本机 App 显示为准）：

| 连接器 | 能干什么 |
|---|---|
| **QQ 邮箱** | 读邮件（近一个月收件箱）、发邮件、删邮件 |
| **腾讯文档** | 搜索文档、预览内容、引用段落、回写修改（2026 年 4 月深度打通） |
| **腾讯乐享** | 搜索知识库、查询内容、协助创建和管理 |
| **腾讯会议** | 拉取会议纪要、提取决议和待办 |
| **TAPD** | 读项目管理数据（需求、缺陷、迭代） |
| **企业微信** | 长链接稳定接入、推送消息、远程触发任务 |
| **自定义连接器** | 自己接其他软件（通过 MCP 协议，技术向） |

**MCP** 是什么（老金翻译）：就是让 AI 调用外部工具的通用协议（可以理解成"AI 世界的 USB 接口标准"），符合这个标准的工具都能被 AI 调用，不用每个工具单独写对接。WorkBuddy 的自定义连接器用的就是这个协议。

准备清单：

```text
✅ WB-04 学完，会用技能
✅ 有要接的腾讯软件账号（QQ 邮箱、腾讯文档至少一个）
✅ 账号有积分（连接器调用会消耗积分）
✅ 知道自己要解决什么问题（"我想让 AI 帮我处理邮件"）
```

## 第一步：接通 QQ 邮箱（10 分钟跑通）

老金带你接一个最常用、最容易跑通的——QQ 邮箱。接完你的 AI 就能帮你读邮件、发邮件，不用自己开邮箱翻。

### 1.1 找到连接器入口

主界面找**连接器**或**集成**入口（通常在左侧栏，跟"专家""技能"并列）。点进去你会看到所有可用的连接器列表，每个连接器一张卡片，写着它能干什么。

### 1.2 接通 QQ 邮箱

找到 QQ 邮箱卡片，点**添加**或**连接**：

```text
1. 点 "添加 QQ 邮箱"
2. 弹出一个二维码
3. 打开手机 QQ 邮箱 App，扫这个二维码
4. 手机上确认授权（会列出 WorkBuddy 能干什么：读邮件、发邮件、删邮件）
5. 浏览器弹出最终确认页，点 "同意"
6. 回到 WorkBuddy，QQ 邮箱卡片变成 "已连接" 状态
```

整个过程不到 30 秒。

### 1.3 第一次实战：让 AI 帮你处理邮件

接通后回到对话界面，召唤任意专家（或直接对话），发这段：

```text
我接通了 QQ 邮箱连接器。
帮我做三件事：
1. 看看我最近一周收到的邮件，挑出 3 封最重要的
2. 每封邮件用一句话总结核心内容 + 标注是否需要我回复
3. 如果有明显是垃圾邮件或广告的，列出来问我是否批量删除

不要主动删任何邮件，等我确认。
```

### 1.4 你会看到什么

```text
- AI 通过连接器读到你最近一周的邮件
- 列出 3 封最重要的，每封一段总结 + 是否需回复的标注
- 单独列出疑似垃圾邮件，等你决定
- 全程不主动删邮件，等你指令
```

### 1.5 接通过程卡住怎么办

```text
❌ 扫码后没反应
   → 检查手机 QQ 邮箱 App 是不是最新版
   → 等 5-10 秒，或刷新二维码重新扫

❌ 授权页提示"权限不足"或"应用未审核"
   → 你登的可能是企业版，企业管理员限制了连接器，问 IT
   → 或换个登录方式（QQ 号 vs 手机号）

❌ 接通了但读不到邮件
   → 检查授权范围（当时是不是只授权了"发邮件"没授权"读邮件"）
   → 在连接器卡片上点"管理"或"权限"，重新授权完整范围

❌ 接通了一段时间后失效
   → 长时间不用、或对方平台 token 过期会断开
   → 回到连接器卡片重新点"重新连接"或"刷新授权"
```

## 第二步：接通腾讯文档（最实用，重点学）

腾讯文档是 WorkBuddy 接得最深的一个——2026 年 4 月正式深度打通。接通后你的 AI 能直接搜索、预览、引用、**回写**腾讯文档，不用下载、上传、来回切换。

### 2.1 为什么这个连接器最值

```text
✅ 国内办公最常用的文档工具之一
✅ 接通后 AI 能直接读你的文档当上下文（不用复制粘贴）
✅ AI 改完内容能直接回写到文档（不用手动同步）
✅ 团队共享文档时，AI 协作无障碍
```

### 2.2 接通步骤

```text
1. 在连接器列表找 "腾讯文档"
2. 点 "添加" 或 "连接"
3. 弹出授权页，选登录方式（微信登录 / 手机号登录）
4. 看清楚 WorkBuddy 申请的权限（搜索/读取/编辑文档）
5. 点 "继续" / "同意"
6. 回到 WorkBuddy，腾讯文档卡片变成 "已连接"
```

### 2.3 第一次实战：让 AI 读你的文档

接通后，在对话里发：

```text
我接通了腾讯文档连接器。
帮我找一下我所有标题含 "周报" 的文档，列出文件名 + 最后修改时间。
然后挑最近修改的那一份，总结它的核心内容，并指出有哪些待办项还没完成。
```

### 2.4 你会看到什么

```text
- AI 调用连接器，搜索你的腾讯文档
- 列出所有标题含"周报"的文档（文件名 + 修改时间）
- 自动选最近那份，读取内容
- 输出总结 + 待办项清单
- 待办项旁边标"已完成/未完成"
```

### 2.5 进阶：让 AI 回写文档

不只是读，AI 还能帮你改文档：

```text
"帮我在《2026 Q3 周报-第32周》这份文档最后追加一段：
'下周重点：完成产品发布会的物料准备。'
追加完告诉我，不要改其他内容。"
```

AI 会调用连接器的写权限，直接在文档末尾加这段，不动其他段落。

### 2.6 腾讯文档连接器的边界

```text
🚫 不会改你没授权的文档（授权范围由你定）
🚫 不会删除文档（通常只授权读写，不授权删除）
🚫 协同编辑时不会覆盖别人的修改（带版本感知）
✅ 团队共享文档 AI 也能读（前提是你有读权限）
```

## 第三步：接通企业微信（团队场景必备）

企业微信是 WorkBuddy 团队场景的核心入口——长链接稳定接入，能推送消息、远程触发任务。

### 3.1 企业微信接通的特殊性

企业微信连接器**通常需要管理员授权**（个人没法随便接），所以这条更适合团队部署场景。

```text
个人用户：跳过这步，看第四步
团队负责人/IT：继续看下面
```

### 3.2 管理员接通流程

```text
1. 企业微信管理后台 → 应用管理 → 找 WorkBuddy 或自建应用
2. 配置可见范围（哪些部门/员工能用）
3. 授权需要的权限（发消息、读通讯录、读会议等）
4. 员工在企业微信里看到 WorkBuddy 应用，点进去授权
5. 接通后员工可以用企业微信给 WorkBuddy 发指令
```

### 3.3 接通后能干什么

```text
- 远程触发：在企业微信里给 WorkBuddy 发"生成今日工作汇报"，它桌面端开始跑
- 接收推送：AI 任务跑完，结果直接推到你的企业微信
- 跨端接力：桌面开了任务，企业微信里继续查看进度
- 群协作：在群里 @ WorkBuddy 让它处理团队任务（需配置）
```

这部分细节多，团队部署篇老金放在 WB-10 详细讲。

## 第四步：接通其他常用连接器

老金把剩下几个常用连接器简要讲一下，你按需接。

### 4.1 腾讯会议

接通后能：

```text
- 拉取你最近的会议列表
- 提取某次会议的纪要（如果开启了录音转文字）
- 整理出决议项、待办项、参会人
```

适合：开完会想让 AI 帮你出会议纪要、追踪待办的人。

### 4.2 腾讯乐享

腾讯乐享是腾讯内部知识管理工具，很多公司在用。接通后能：

```text
- 搜索公司知识库的内容
- 引用知识库文章作上下文
- 协助创建和管理知识库条目
```

适合：公司用乐享做内部知识库的团队。

### 4.3 TAPD

TAPD 是腾讯的项目管理工具。接通后能：

```text
- 读需求、缺陷、迭代数据
- 自动汇总项目进度
- 生成项目周报
```

适合：用 TAPD 管研发项目的团队。

### 4.4 自定义连接器（技术向）

广场上没有的软件，你可以用 MCP 协议自己接。流程：

```text
1. 在连接器列表找 "自定义连接器"
2. 安装自定义的 MCP 服务（需要技术同事配置）
3. 配置服务地址、权限范围
4. 测试连接，确认能用
```

适合：公司内部系统、特殊 SaaS 工具想接进 WorkBuddy 的团队。小白别碰，让技术同事来。

## 第五步：连接器的权限和安全

老金这一步是为你好——AI 能读你的邮件、改你的文档，权限很大，必须管好。

### 5.1 授权时看清楚

每次接通连接器，授权页会列出 WorkBuddy 申请的权限。老金建议你：

```text
✅ 看清楚每条权限（读邮件？发邮件？删邮件？）
✅ 只给必要的（如果只想读，就别勾写/删）
✅ 第一次接保守一点，后面需要再加
❌ 别图省事全部勾选"全部权限"
```

### 5.2 定期清理

```text
✅ 每月检查一次"已连接"列表
✅ 不再用的连接器及时断开（点"解绑"或"断开"）
✅ 涉及敏感账号的连接器，离职/换岗前一定断开
```

### 5.3 企业版的额外管控

如果你登的是企业版，管理员通常能：

```text
- 控制哪些连接器能用、哪些禁用
- 设置每个连接器的权限范围
- 审计所有连接器的调用记录
- 强制敏感连接器走审批
```

涉及公司数据的连接器，**先问 IT 同意再接**，别自己私接。

### 5.4 万一出事了怎么办

```text
🚨 AI 误删了邮件 / 误改了文档
   → 立刻断开那个连接器（点"解绑"，AI 立刻失去访问权）
   → 去对应软件的回收站/历史版本恢复（腾讯文档有版本历史）
   → 在 WorkBuddy 里关闭那个连接器的"写"权限，只保留"读"
   → 复盘：是授权过宽、还是任务描述不清，调整后重新接
```

## 常见问题

**Q1：连接器要钱吗？**
连接器本身接通免费，但**调用连接器会消耗积分**。每个连接器的消耗看具体动作（读邮件便宜、批量处理贵）。

**Q2：接了 QQ 邮箱，AI 会读我所有邮件吗？**
默认只读近一个月的收件箱，不会翻历史所有。授权时你能看到具体范围，按需给。你不放心可以只授权"发邮件"不授权"读"。

**Q3：腾讯文档接通后，AI 会改我所有文档吗？**
不会。AI 只能改你授权范围内的、且你任务里明确指定的文档。不会乱改。但老金建议敏感文档（合同、财务）单独放一个账号，别接进 WorkBuddy。

**Q4：企业微信连接器个人能接吗？**
个人接不了，要企业管理员授权。个人用户想用企业微信推消息，可以让团队负责人看 WB-10 部署。

**Q5：连接器调用失败怎么办？**
常见原因：网络、授权过期、对方平台限流、权限不足。先看错误提示，按提示处理。还不行就断开重接。

**Q6：我能同时接多个连接器吗？**
能。同时接 QQ 邮箱、腾讯文档、腾讯会议都没问题。但**同时启用的连接器多，AI 决策会更慢**（要判断该调哪个）。常用就开，不常用就关。

**Q7：自定义连接器难吗？**
要懂 MCP 协议、要会配置服务。小白别碰，让公司技术同事来。如果想自己跑通一个，让 WorkBuddy 帮你生成简单的是可行的。

**Q8：接通连接器会被公司监控吗？**
企业版下，管理员的审计能看到你用了哪些连接器、调用了多少次。这是企业治理需要，正常。具体监控范围看公司政策。
