## 先搞清：连接器是什么、跟技能啥区别

老金这一节讲清楚两个容易混的概念。

**连接器**（Connector）= 把 WorkBuddy 接到外部软件的桥梁，让 AI 能直接读写那个软件里的数据。它是技能的一种特殊形态——专门用来对接外部服务的。

打个比方：

```text
技能     = AI 手里的小工具（网页搜索、文件读写这种通用动作）
连接器   = 专门对接某个具体软件的桥（QQ 邮箱连接器、腾讯文档连接器）
```

连接器按各外部服务的登录、授权和工具范围工作，实现形态可能是 MCP + CLI 或 Skill + CLI。不同服务的连接方式不同，不能把企微助理的长连接机制套到全部连接器。

**WorkBuddy 目前接通的腾讯生态**（老金按 2026-09-13 核查的情况列，新连接器会持续上线，以你本机 App 显示为准）：

| 连接器 | 能干什么 |
|---|---|
| **QQ 邮箱** | 读邮件（近一个月收件箱）、发邮件、删邮件 |
| **腾讯文档** | 搜索文档、预览内容、引用段落、回写修改（2026 年 4 月深度打通） |
| **腾讯乐享** | 搜索知识库、查询内容、协助创建和管理 |
| **腾讯会议** | 拉取会议纪要、提取决议和待办 |
| **TAPD** | 读项目管理数据（需求、缺陷、迭代） |
| **企业微信** | 长链接稳定接入、推送消息、远程触发任务 |
| **自定义连接器** | 自己接其他软件（通过 MCP 协议，技术向） |

**MCP** 是什么（老金翻译）：就是让 AI 调用外部工具的通用协议（可以理解成"AI 世界的 USB 接口标准"），符合这个标准的工具都能被 AI 调用，不用每个工具单独写对接。WorkBuddy 的自定义连接器用的就是这个协议。

准备清单：

```text
✅ WB-04 学完，会用技能
✅ 有要接的腾讯软件账号（QQ 邮箱、腾讯文档至少一个）
✅ 账号有积分（连接器调用会消耗积分）
✅ 知道自己要解决什么问题（"我想让 AI 帮我处理邮件"）
```

## 第一步：接通 QQ 邮箱（10 分钟跑通）

老金带你接一个最常用、最容易跑通的——QQ 邮箱。接完你的 AI 就能帮你读邮件、发邮件，不用自己开邮箱翻。

### 1.1 找到连接器入口

在左侧栏打开**专家·技能·连接器 → 连接器**页签。若一级菜单里没有这个入口，先检查“更多”。这里会列出连接器卡片；新建任务时也可以通过输入框左下角的 **+ → 连接器**选择需要的能力。

### 1.2 接通 QQ 邮箱

找到 QQ 邮箱卡片，点**添加**或**连接**：

```text
1. 在 QQ 邮箱卡片右侧点“+”，打开 QQ 邮箱授权网页
2. 使用 QQ 邮箱 App 7.1.5、鸿蒙版 0.2.9 或更新版本扫码
3. 在手机上核对账号信息、读取近一个月收件箱邮件、发送邮件等权限；删除邮件是可选项，本次练习不需要
4. 确认后点“同意授权”
5. 授权成功后，在浏览器弹窗中点“打开”完成连接；直接关闭网页可能中断流程
6. 回到 WorkBuddy，检查卡片是否出现绿色圆点和“去对话”按钮
```

完成时间取决于网络、账号状态和授权过程；以卡片显示连接成功为准。

### 1.3 第一次实战：让 AI 帮你处理邮件

接通后回到对话界面，召唤任意专家（或直接对话），发这段：

```text
我接通了 QQ 邮箱连接器。
帮我做三件事：
1. 看看我最近一周收到的邮件，挑出 3 封最重要的
2. 每封邮件用一句话总结核心内容 + 标注是否需要我回复
3. 如果有明显是垃圾邮件或广告的，列出来问我是否批量删除

不要主动删任何邮件，等我确认。
```

### 1.4 你会看到什么

```text
- AI 通过连接器读到你最近一周的邮件
- 列出 3 封最重要的，每封一段总结 + 是否需回复的标注
- 单独列出疑似垃圾邮件，等你决定
- 全程不主动删邮件，等你指令
```

### 1.5 接通过程卡住怎么办

```text
❌ 扫码后没反应
   → 检查手机 QQ 邮箱 App 是不是最新版
   → 等 5-10 秒，或刷新二维码重新扫

❌ 授权页提示"权限不足"或"应用未审核"
   → 你登的可能是企业版，企业管理员限制了连接器，问 IT
   → 或换个登录方式（QQ 号 vs 手机号）

❌ 接通了但读不到邮件
   → 核对连接状态、账号和实际授权页，检查本次请求是否在可读取范围内
   → 按卡片当前提供的流程重新连接；不假定每项读取权限都可独立勾选

❌ 接通了一段时间后失效
   → 长时间不用、或对方平台 token 过期会断开
   → 回到连接器卡片重新点"重新连接"或"刷新授权"
```

## 第二步：接通腾讯文档（最实用，重点学）

腾讯文档是 WorkBuddy 接得最深的一个——2026 年 4 月正式深度打通。接通后你的 AI 能直接搜索、预览、引用、**回写**腾讯文档，不用下载、上传、来回切换。

### 2.1 为什么这个连接器最值

```text
✅ 国内办公最常用的文档工具之一
✅ 接通后 AI 能直接读你的文档当上下文（不用复制粘贴）
✅ AI 改完内容能直接回写到文档（不用手动同步）
✅ 团队共享文档时，AI 协作无障碍
```

### 2.2 接通步骤

```text
1. 在连接器列表找 "腾讯文档"
2. 点 "添加" 或 "连接"
3. 弹出授权页，选登录方式（微信登录 / 手机号登录）
4. 看清楚 WorkBuddy 申请的权限（搜索/读取/编辑文档）
5. 点 "继续" / "同意"
6. 回到 WorkBuddy，腾讯文档卡片变成 "已连接"
```

### 2.3 第一次实战：让 AI 读你的文档

接通后，在对话里发：

```text
我接通了腾讯文档连接器。
帮我找一下我所有标题含 "周报" 的文档，列出文件名 + 最后修改时间。
然后挑最近修改的那一份，总结它的核心内容，并指出有哪些待办项还没完成。
```

### 2.4 你会看到什么

```text
- AI 调用连接器，搜索你的腾讯文档
- 列出所有标题含"周报"的文档（文件名 + 修改时间）
- 自动选最近那份，读取内容
- 输出总结 + 待办项清单
- 待办项旁边标"已完成/未完成"
```

### 2.5 进阶：让 AI 回写文档

不只是读，AI 还能帮你改文档：

```text
"帮我在《2026 Q3 周报-第32周》这份文档最后追加一段：
'下周重点：完成产品发布会的物料准备。'
追加完告诉我，不要改其他内容。"
```

AI 会调用连接器的写权限，直接在文档末尾加这段，不动其他段落。

### 2.6 腾讯文档连接器的边界

```text
✅ 先核对当前账号与目标文档的实际权限，再确认本次任务的读写范围
✅ 编辑前保存版本或副本，完成后打开原文核对差异
⚠️ 不把“已连接”理解成不会误删、不会覆盖协作者的修改；本次只在练习副本中追加内容
✅ 团队共享文档是否可读取，以该账号实际访问权限和连接器支持范围为准
```

## 第三步：接通企业微信（团队场景必备）

企业微信是 WorkBuddy 团队场景的核心入口——长链接稳定接入，能推送消息、远程触发任务。

### 3.1 企业微信接通的特殊性

企业微信远程接入使用的是**企微助理**，需要一个有权创建智能机器人的企业微信账号。官方分别提供管理员和普通成员流程；能不能创建取决于企业的权限设置，不能一概说普通成员接不了。只做个人文件练习时，可以先跳过这一步。

### 3.2 管理员接通流程

```text
1. 管理员在企业微信管理后台进入“安全与管理 → 管理工具 → 智能机器人 → 创建机器人”；有创建权限的普通成员可从客户端“工作台 → 智能机器人应用 → 创建机器人”进入
2. 如进入 AI 自动生成页，选择“手动创建”，再选“API 模式创建”
3. 填机器人名称、可见或可使用成员范围，按页面要求保存，再选择“使用长连接”
4. 按官方企微助理指南，把机器人与 WorkBuddy 的“设置 → 助理设置”完成绑定；凭证只填写在对应配置界面，不贴进任务对话或截图
5. 保持电脑、网络和 WorkBuddy 在线，在已配置机器人中发送一条小任务验证
```

### 3.3 接通后能干什么

```text
- 远程触发：在企业微信里给 WorkBuddy 发"生成今日工作汇报"，它桌面端开始跑
- 接收推送：AI 任务跑完，结果直接推到你的企业微信
- 跨端接力：桌面开了任务，企业微信里继续查看进度
- 群协作：在群里 @ WorkBuddy 让它处理团队任务（需配置）
```

这部分细节多，团队部署篇老金放在 WB-10 详细讲。

## 第五步：连接器的权限和安全

老金这一步是为你好——AI 能读你的邮件、改你的文档，权限很大，必须管好。

### 5.1 授权时看清楚

每次接通连接器，授权页会列出 WorkBuddy 申请的权限。老金建议你：

```text
✅ 阅读授权页列出的访问范围与操作能力
✅ 页面确实提供可选项时，只选择当前任务需要的范围
✅ 某项权限不能独立关闭而你不能接受时，取消连接，改用少量练习附件
✅ 先用练习账号或非敏感材料验证，不假定授权页都有“全部权限”或独立读写勾选
```

### 5.2 定期清理

```text
✅ 每月检查一次"已连接"列表
✅ 不再用的连接器及时断开（点"解绑"或"断开"）
✅ 涉及敏感账号的连接器，离职/换岗前一定断开
```

### 5.3 企业版的额外管控

如果你登的是企业版，管理员通常能：

```text
- 控制哪些连接器能用、哪些禁用
- 设置每个连接器的权限范围
- 审计所有连接器的调用记录
- 强制敏感连接器走审批
```

涉及公司数据的连接器，**先问 IT 同意再接**，别自己私接。

### 5.4 万一出事了怎么办

```text
🚨 AI 误删了邮件 / 误改了文档
   → 先停止相关任务，在连接器管理页完成解绑并核对状态
   → 到外部平台检查授权与已产生的修改，按回收站或版本历史恢复
   → 本次对话取消启用，与管理页解绑是不同操作；解绑也不会自动撤回已发出的内容
   → 重新使用前核对可选权限与练习结果；没有独立写权限开关时，不把“只保留读”写成可点按钮
```

## 常见问题

**Q1：连接器要钱吗？**
核对连接器依赖的服务是否另收费，以及 AI 任务的实际用量。不能按“读邮件便宜、批量处理贵”推算固定价格；先用小材料试跑，再查看当前账号的用量记录。

**Q2：接了 QQ 邮箱，AI 会读我所有邮件吗？**
官方 QQ 邮箱授权说明列出读取收件箱近一个月邮件、发送邮件，删除邮件为可选项。授权页提供哪些可选项，就按实际页面选择；不能接受读取范围时取消连接，不假定读取与发送都能各自独立关闭。

**Q3：腾讯文档接通后，AI 会改我所有文档吗？**
可访问范围受账号与文档权限限制，但仍要核对本次任务的目标和变更。先在练习副本中追加一段，打开原文查看差异；不要把“已授权”理解为一定不会误改。敏感材料按团队允许的数据处理方式决定是否接入。

**Q4：企业微信连接器个人能接吗？**
官方企微助理支持管理员和有创建智能机器人权限的普通成员配置。先检查企业是否允许你创建 API 模式机器人；没有权限时找管理员。结果通知 bot 与能接收任务的企微助理用途不同，按 [官方企微接入指南](https://www.workbuddy.cn/docs/workbuddy/Wecom-Guide)配置对应通道。

**Q5：连接器调用失败怎么办？**
常见原因：网络、授权过期、对方平台限流、权限不足。先看错误提示，按提示处理。还不行就断开重接。

**Q6：我能同时接多个连接器吗？**
能。同时接 QQ 邮箱、腾讯文档、腾讯会议都没问题。但**同时启用的连接器多，AI 决策会更慢**（要判断该调哪个）。常用就开，不常用就关。

**Q7：自定义连接器难吗？**
要懂 MCP 协议、要会配置服务。小白别碰，让公司技术同事来。如果想自己跑通一个，让 WorkBuddy 帮你生成简单的是可行的。

**Q8：接通连接器会被公司监控吗？**
企业版下，管理员的审计能看到你用了哪些连接器、调用了多少次。这是企业治理需要，正常。具体监控范围看公司政策。
