## 第一部分：账号和积分体系

老金先把账号体系彻底讲清，因为这是掏钱决策和安全管理的地基。

### 1.1 三层账号形态

WorkBuddy 的账号分三层，对应不同人群：

| 形态 | 给谁 | 核心特征 |
|---|---|---|
| **个人版** | 个人用户、自由职业者、试用 | 单账号、订阅制、跟 CodeBuddy 共享积分 |
| **企业 SaaS 版** | 团队、小公司、中型企业 | 按席位计费、集中管理、团队共享 |
| **专有云企业版** | 大企业、强合规需求 | 私有部署、数据驻留可控、单价更高 |

### 1.2 WorkBuddy 和 CodeBuddy 的账号关系

老金再强调一次（很重要）：

```text
- 同一个腾讯账号、同一套积分池
- 订一份，两个产品通常都能用
- 不用分别注册、分别付费
```

所以你看到 WorkBuddy 的定价，可能跟 CodeBuddy 是同一套——别被两个产品名搞混。

### 1.3 价格框架（2026 年 8 月）

老金把当前价格框架列给你，但**先念三遍**：**AI 产品调价频繁，下单前一定打开 App 或官网核对当前价格**。

个人版（月付/年付）：

```text
- 免费版：0 元，有限免费积分额度
- 专业版：约 99 元/月（年付通常有优惠）
- 年度版：约 119 元/年起（折算更便宜）
```

企业版（按人头/月）：

```text
- SaaS 企业版：约 199 元/人/月
- 专有云企业版：约 316 元/人/月（2026-05-15 起从 158 元调整上来）
```

### 1.4 积分机制（必懂）

**积分**是 WorkBuddy 的消耗单位，类似游戏钻石。规则：

```text
- 每月按套餐给积分额度（免费版少、付费版多）
- 不同任务扣不同积分（普通对话便宜，专家团是单专家 3-5 倍）
- 不同模型扣不同（旗舰模型扣得多）
- 用完了任务跑不动，等下月重置或加购
```

**积分消耗优先级**（先扣哪个）：

```text
1. 免费体验额度（最先扣）
2. 赠送积分（按到期顺序扣）
3. 付费积分（最后扣）
```

### 1.5 怎么选账号

```text
个人尝鲜 → 免费版跑通，再决定升不升专业版
个人重度 → 专业版月付试一个月，顺手转年付
小团队（5-20 人）→ SaaS 企业版，按席位算清
中大型团队 → SaaS 企业版 + 团队管理
大企业 + 合规 → 专有云企业版，找腾讯销售谈
不确定 → 先个人版摸清，再决定升级
```

## 第二部分：企业部署和安全

这部分主要给团队负责人、IT 管理员看。

### 2.1 企业版的团队管理

企业 SaaS 版下，管理员能做：

```text
✅ 集中开账号、按席位管理
✅ 设权限：谁能用专家团、谁能接哪些连接器、谁能建知识库
✅ 审计：谁用了多少积分、调用了什么数据、跑了什么自动化
✅ 数据隔离：部门之间、敏感项目之间隔离
✅ 单点登录：对接公司 SSO（部分版本支持）
```

### 2.2 专有云版的特点

专有云（私有部署）适合：

```text
✅ 金融、政企、医疗等强合规行业
✅ 数据不能出公司网络的需求
✅ 要做深度定制（接公司内部系统）
✅ 需要完全审计和控制
```

代价：

```text
⚠️ 单价更高（约 316 元/人/月）
⚠️ 部署周期长（要腾讯团队配合）
⚠️ 维护成本（要有 IT 团队）
⚠️ 升级滞后（新功能上线比 SaaS 版慢）
```

### 2.3 安全边界（必须划清）

老金把企业用 WorkBuddy 的安全边界划清，避免出事：

```text
🚫 别让 AI 直接处理真正机密
   - 客户身份证号、银行卡号、医疗记录
   - 未公开的财务核心数据、股权结构
   - 涉密政府数据、军工资质相关

⚠️ 涉及敏感数据时的正确做法
   - 先脱敏（去掉真实姓名、ID、金额）
   - 用私有部署（专有云版）
   - 限制授权范围（最小权限原则）
   - 配审计和告警

✅ 企业版必做的安全配置
   - 开启审计日志、定期 review
   - 关键连接器走审批（QQ 邮箱、企业微信）
   - 自动化任务限流（防积分失控）
   - 共享知识库定期清理过期资料
   - 离职员工及时停账号
```

### 2.4 合规和隐私

```text
- 数据驻留：SaaS 版数据在腾讯云，专有云在你指定位置
- 数据使用：通常不用于训练通用模型（具体看协议）
- 审计权限：企业版管理员有审计权
- 数据导出：通常支持导出你的数据，方便迁移或备份
- 法务：企业签约前让法务看条款，特别是数据归属和保密
```

### 2.5 团队推广的策略

老金给团队负责人的推广建议：

```text
✅ 别一上来全员推开（风险大、消耗高）
✅ 找 3-5 个种子用户先试 2-4 周
✅ 让种子用户沉淀团队专属专家团、知识库、自动化
✅ 出团队使用规范（哪些能干、哪些不能）
✅ 培训后再扩大到全员
✅ 每月 review 使用情况，优化配置
```

### 3.3 按场景选工具

老金按典型场景给你选型建议：


### 3.4 共存策略

**老金的核心观点：四工具可以共存，不二选一**。

```text
开发者本人：
   - 主力：Claude Code（写代码）
   - 辅助：WorkBuddy（写周报、调研、办公）
   - 协作：Codex（多入口、Cloud 长任务）

团队部署：
   - 技术团队：Claude Code + Codex
   - 业务团队：WorkBuddy
   - 数据敏感场景：OpenClaw 私有部署
   - 全公司：按部门分工具，不强制统一
```

### 3.5 一个真实的多工具组合案例

老金给你看一个真实的工作流：

```text
场景：产品发布会的全流程支持

1. 用 WorkBuddy 做市场调研（基于腾讯文档、QQ 邮件客户反馈）
   → 产出：竞品分析、目标用户画像

2. 用 WorkBuddy 写发布会 PPT 大纲和讲稿
   → 产出：PPT 草稿、主持人讲稿

3. 用 Claude Code 开发发布会现场的 demo 应用
   → 产出：可运行的 demo 代码

4. 用 Codex 做 PR（多入口、团队 Review）
   → 产出：合并到主分支的代码

5. 用 WorkBuddy 自动化：每天监控发布会相关舆情、媒体反馈
   → 产出：每日舆情简报推到企业微信

6. 发布会结束后，用 WorkBuddy 整理媒体采访记录、出复盘报告
   → 产出：复盘文档存腾讯文档
```

一个项目，四个工具各司其职，效率比单用任何一个高得多。

## 常见问题

**Q1：WorkBuddy 会替换掉我们团队的开发者工具吗？**
不会。开发者工具（Claude Code、Codex）和 WorkBuddy 是互补关系。技术团队继续用开发者工具，业务/办公团队用 WorkBuddy，按角色分配。

**Q2：企业版最便宜要多少钱？**
SaaS 企业版约 199 元/人/月，5 人团队一年约 12000 元。具体议价空间看腾讯销售。专有云版单价高（316 元/人/月）但有私有部署价值。

**Q3：小团队有必要上企业版吗？**
看管理需求。如果只是几个人各用各的，个人专业版就行。如果要集中付费、统一管理、共享知识库/专家团、做审计，企业版更合适。

**Q4：数据安全吗？会被腾讯拿去训练吗？**
通常企业协议明确不用于训练通用模型。但具体条款看签约内容。敏感数据建议脱敏或用专有云版。法务 review 是必须的。

**Q5：能用 WorkBuddy 替代公司现有的 OA/CRM 吗？**
不能完全替代。WorkBuddy 是 AI 助手，不是 OA/CRM 系统。它能**辅助**你处理 OA/CRM 里的内容（通过连接器），但核心业务系统还是专业的 OA/CRM。

**Q6：本仓库的四条主线，老金自己用哪几个？**
老金写代码用 Claude Code，写教程和办公用 WorkBuddy，做长任务协作用 Codex，实验性项目偶尔用 OpenClaw。每个工具都有它的位置，不二选一。

**Q7：这套教程会持续更新吗？**
会。WorkBuddy 和其他三个工具都在快速迭代，老金会定期 review 和更新。你关注本仓库的提交记录或公众号"老金带你玩AI"就能跟上。

**Q8：学完这 11 篇我算 WorkBuddy 高手了吗？**
算入门到熟练。要成高手还要持续实战——把 WorkBuddy 真正用进你的日常工作，遇到问题查官方文档和社区，沉淀自己的专家团和知识库。教程给你方法和起点，真正的能力是练出来的。
