# WB-08 WorkBuddy 多端协同：桌面、手机、微信无缝接力

老金写这篇教程的目的——让你学会在多个设备之间无缝使用 WorkBuddy。学完这篇，你能在桌面开了个任务出门用手机继续接、在地铁上用微信给 WorkBuddy 下指令让它桌面端跑、在团队群里直接 @ 它处理协作任务——不再被"必须坐在电脑前"束缚。

这是 WorkBuddy 区别于 Claude Code、Codex 这类"必须用电脑"的工具的**关键体验优势**。

## 先搞清：WorkBuddy 有哪些端

老金把 WorkBuddy 的多端形态梳理一下，让你先建立整体认知：

```text
1. 桌面 App（Windows / macOS）：主力工作台，功能最全
2. 微信公众号：轻量交互，看任务状态、收推送
3. 企业微信：团队协作主力入口，远程触发、群内 @
4. 微信小程序：手机上继续桌面任务、查看产出
5. 网页版（部分能力）：浏览器轻量使用
```

**核心机制**：**同一个微信账号打通所有端**。你在桌面开的活动、任务、知识库、连接器，在手机端都能看到继续用——数据是云同步的，不用手动导。

**多端协同的三大典型场景**：

```text
场景一：跨端接力
   桌面开了任务 → 出门 → 手机继续看进度 / 接收结果

场景二：远程触发
   你在地铁用微信发指令 → 桌面端开始跑 → 跑完推回手机

场景三：移动办公
   手机随时查知识库、问专家、收自动化推送
```

准备清单：

```text
✅ WB-02~07 学完，会基本操作
✅ 桌面 App 已装并登录
✅ 手机装了微信（个人版或企业版）
✅ 接通过至少 1 个连接器（WB-05，方便推送）
✅ 账号有积分（多端任务都消耗积分）
```

## 第一步：把手机端接上（10 分钟）

### 1.1 微信公众号方式（最简单）

打开手机微信，搜"WorkBuddy"或"腾讯 WorkBuddy"，找官方公众号关注。点关注后通常会弹引导，授权登录（用同一个微信账号）。

接通后你能用公众号：

```text
- 跟它对话（轻量任务，比如查个资料、问个问题）
- 接收自动化推送（每天的工作摘要会推到这里）
- 查看任务状态（桌面跑的任务进度）
```

### 1.2 微信小程序方式（功能更全）

微信搜"WorkBuddy"小程序，授权登录后你能：

```text
- 看所有任务列表和产出
- 继续桌面没跑完的任务
- 查看知识库内容
- 接收连接器推送（邮件、文档更新）
- 触发新任务（手机指令，桌面执行）
```

小程序比公众号功能全，比桌面 App 轻量。日常手机端用小程序最合适。

### 1.3 企业微信方式（团队场景）

如果你公司开了 WorkBuddy 企业版，企业微信里会有 WorkBuddy 应用入口，点进去能用全部能力（受公司权限管控）。还能在群里 @ 它处理团队任务。

### 1.4 接通时卡住怎么办

```text
❌ 搜不到 WorkBuddy 公众号/小程序
   → 名字可能用全称或简称，多试几个关键词
   → 让已经用过的人把名片/链接推给你，直接点进去

❌ 授权后没反应
   → 检查登的是不是桌面同一个微信账号
   → 退出重新登，或重启微信

❌ 提示"账号未开通"
   → 你可能登的是不同的微信号，切回桌面的那个
   → 或企业账号没开通移动端权限，问管理员

❌ 企业微信里看不到 WorkBuddy
   → 公司没开通这个应用，问 IT
   → 或你没在可见范围内，让管理员加
```

## 第二步：跨端接力实战（15 分钟）

老金带你跑一个完整跨端任务，让你感受"桌面开、手机接"的顺畅。

### 2.1 桌面开任务

在桌面 App 里召唤办公写作专家，发一个会跑几分钟的任务：

```text
基于我的"个人工作资料库"，整理一份本周工作复盘：
- 完成了哪些事
- 没完成的事和原因
- 下周要优先处理的 3 件事
格式：Markdown，800 字以内。
```

发出去后，**别等它跑完**，直接锁屏出门。

### 2.2 路上手机查看

打开手机微信 WorkBuddy 小程序，进入任务列表，你会看到刚才那个任务正在跑（或已完成）。如果完成了，直接在手机上看产出；如果还在跑，等它完成会推送通知给你。

### 2.3 在手机上继续操作

看完产出后，你可以直接在小程序里继续提问：

```text
"刚才那份复盘里没完成的事，帮我细化一下'原因'部分，
我要拿这部分跟 leader 沟通调整下周计划。"
```

WorkBuddy 会在同一个对话上下文里继续干，知道你之前任务的全部背景。

### 2.4 推送给同事

复盘改完后，用小程序的分享功能，把这份文档推给你的企业微信同事，或导出到腾讯文档（通过连接器）。

### 2.5 跨端接力的实际价值

```text
✅ 碎片时间利用（通勤、等候时手机处理）
✅ 不被设备束缚（出门也能继续工作）
✅ 即时响应（桌面跑完立刻手机收到，不用回电脑看）
✅ 协作顺畅（手机直接转给同事，不用导来导去）
```

## 第三步：远程触发实战（手机指令桌面干活）

这部分 WB-07 讲过基础，这里补完整场景。

### 3.1 典型场景：出差时让桌面跑复杂任务

你要出差三天，但手头有个需要桌面算力的复杂任务。你可以：

```text
出差途中，手机发指令：
"基于我的'客户资料库'，整理出 Top 10 客户的全年合作情况，
按合同金额排序，每家附上关键节点和未完成承诺。
跑完推到我的企业微信，我明天见客户用。"

桌面端 App（家里/公司电脑只要开着）接到任务开始执行：
- 检索知识库
- 召唤销售专家产出
- 通过连接器推送到你的企业微信

你晚上到酒店打开企业微信，结果已经在那等你了。
```

### 3.2 远程触发的注意点

```text
⚠️ 桌面 App 必须保持在线状态
   - 别让电脑睡眠（设置里调成"屏幕关但系统不睡"）
   - 网络要稳（断网任务跑不了）
   - 重启电脑后 App 要能自动启动（设置开机自启）

⚠️ 远程指令要写清楚
   - 别发"看看我那个东西"，AI 不知道指啥
   - 写明任务、目标、输出（参考 WB-03 黄金提问模板）

⚠️ 大任务别远程触发
   - 跑 30 分钟以上的复杂任务，远程触发难监控
   - 大任务先在桌面跑，远程只用来触发轻量任务和查进度
```

## 第四步：微信群里用 WorkBuddy（团队协作）

### 4.1 群里 @ WorkBuddy

如果公司开了企业微信群集成，你可以在群里直接 @ WorkBuddy 让它处理任务：

```text
群聊场景：
@WorkBuddy 帮我看看刚才发的那个项目方案，
从合规角度挑出 3 个最值得关注的风险点，简短回复。

WorkBuddy 会：
- 读取群里刚才的上下文（项目方案）
- 召唤法务专家
- 简短回复到群里
```

### 4.2 群协作的注意点

```text
⚠️ 群里 @ 它会消耗你的积分（你触发就扣你的）
⚠️ 群里消息它能看到，但只回应被 @ 的内容
⚠️ 涉及机密的话题别在群里让它处理（其他人能看到）
⚠️ 群里回复要简短（长回复刷屏），复杂任务让它私聊给你
```

### 4.3 团队任务分担

群里 @ WorkBuddy 还能做"团队分担"——比如有同事问了个问题，你让它回答，它帮你消化后你再回复同事。适合你不想直接答但又不好推脱的场景。

## 第五步：多端数据同步和冲突处理

### 5.1 哪些数据会同步

```text
✅ 任务历史和产出（云端存）
✅ 知识库内容（云端存）
✅ 专家和技能配置（云端存）
✅ 连接器授权状态（云端存）
✅ 个人偏好设置（云端存）
```

桌面、手机看到的都是同一份。

### 5.2 同时操作冲突怎么办

```text
场景：桌面在改一份文档，手机同时在改同一份
处理：通常"最后保存的覆盖前面的"，部分支持协同编辑的不冲突
建议：同一时间只用一端操作复杂任务，避免冲突

场景：桌面跑着任务，手机又触发新任务
处理：通常排队执行（桌面任务跑完再跑手机的）
建议：错开触发，别短时间内多端一起压任务
```

### 5.3 离线状态怎么办

```text
- 桌面断网：本地任务还能跑（不依赖云的），云端任务暂停
- 手机断网：看不了任务列表，等有网再同步
- 同步延迟：通常几秒到几分钟，复杂操作稍长
```

## 第六步：多端使用的安全注意

老金这一步是为你好——多端便利也意味着风险面变大。

### 6.1 手机端的安全

```text
✅ 手机锁屏加密码（别让别人能直接打开你的微信用 WorkBuddy）
✅ WorkBuddy 小程序可以单独加锁（部分版本支持）
✅ 别在公共/他人手机登录 WorkBuddy 账号
✅ 万一手机丢了：立刻在桌面端"账号设置"里退出所有移动端
```

### 6.2 公共网络的安全

```text
🚫 别在公共 WiFi（咖啡店、机场）触发敏感任务
🚫 别在公共网络下让它读敏感知识库
✅ 出差用流量或个人热点，更安全
```

### 6.3 企业版的多端管控

```text
- 管理员能限制移动端是否能用
- 管理员能限制移动端能访问哪些数据
- 离职/换岗时管理员能远程清除移动端访问权
- 涉密操作通常会强制只允许桌面端
```

## 常见问题

**Q1：手机端要单独付费吗？**
不用。同一个账号所有端通用，积分也共享。

**Q2：手机端功能跟桌面一样全吗？**
不一样。手机端偏轻量交互（看、问、触发），桌面端是主力工作台（建知识库、配连接器、跑复杂任务）。复杂操作建议桌面，手机用来协同和移动场景。

**Q3：桌面没开，手机能触发任务吗？**
看任务类型。**纯云端任务**（基于连接器、知识库）手机能直接触发，桌面不用开。**本地任务**（涉及本地文件、桌面操作）通常要桌面 App 在线。

**Q4：多端登录会冲突吗？**
不冲突，多端可以同时在线。数据实时同步。同时操作同一份内容时要协调（避免覆盖）。

**Q5：手机端能用专家团吗？**
能触发，但手机端看产出体验不如桌面（长文档、表格在手机上看累）。建议手机触发、桌面查看。或者让专家团产出后推送到企业微信/邮箱，手机看摘要。

**Q6：企业微信里的 WorkBuddy 跟个人的 WorkBuddy 是同一个吗？**
看你公司怎么配。如果公司开了企业版，企业微信里的是企业账号（受公司管控），个人微信里的是个人账号。两边数据可能不互通（看公司策略）。

**Q7：手机端消耗积分跟桌面一样吗？**
一样的。同一个账号同一种任务，不分端按积分扣。

**Q8：能不能让 WorkBuddy 主动给我手机推消息（不靠我触发）？**
能。这就是自动化推送（看 WB-07）。配好后到点自动推，不用你触发。
