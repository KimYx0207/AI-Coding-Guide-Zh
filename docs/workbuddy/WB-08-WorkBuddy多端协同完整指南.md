# WB-08 WorkBuddy 多端协同：桌面、手机、微信无缝接力

老金写这篇教程的目的——让你学会在多个设备之间无缝使用 WorkBuddy。学完这篇，你能在桌面开了个任务出门用手机继续接、在地铁上用微信给 WorkBuddy 下指令让它桌面端跑、在团队群里直接 @ 它处理协作任务——不再被"必须坐在电脑前"束缚。

这里重点练习 WorkBuddy 的手机协同与远程助理：先绑定通道，再验证电脑是否接到任务、手机是否收到结果。

## 先搞清：WorkBuddy 有哪些端

老金把 WorkBuddy 的多端形态梳理一下，让你先建立整体认知：

```text
1. 桌面 App（Windows / macOS）：主力工作台，功能最全
2. 微信公众号：轻量交互，看任务状态、收推送
3. 企业微信：团队协作主力入口，远程触发、群内 @
4. 微信小程序：手机上继续桌面任务、查看产出
5. 网页版（部分能力）：浏览器轻量使用
```

**先验证账号和任务**：确认桌面与手机使用同一个 WorkBuddy 账号，再打开同一任务核对标题、产物和能否继续对话。不同端可用的技能、连接器、应用与本地文件范围要分别检查；登录成功不代表所有配置与文件都已经同步。

**多端协同的三大典型场景**：

```text
场景一：跨端接力
   桌面开了任务 → 出门 → 手机继续看进度 / 接收结果

场景二：远程触发
   你在地铁用微信发指令 → 桌面端开始跑 → 跑完推回手机

场景三：移动办公
   手机随时查知识库、问专家、收自动化推送
```

准备清单：

```text
✅ WB-02~07 学完，会基本操作
✅ 桌面 App 已装并登录
✅ 手机装了微信（个人版或企业版）
✅ 接通过至少 1 个连接器（WB-05，方便推送）
✅ 账号有积分（多端任务都消耗积分）
```

## 第一步：把手机端接上（10 分钟）

### 1.1 微信助理方式

在桌面 WorkBuddy 打开**头像 → 设置 → 助理设置**，按官方微信助理或微信客服号指南选择并完成对应通道配置，再到已绑定的微信对话发送一个小任务。电脑要保持开机、联网并运行 WorkBuddy。

关注一个同名公众号不等于已经完成助理绑定，也不保证它可以接收本章所有通知。查看助理页执行记录与手机实际回复，确认这条链路跑通后再使用自己的材料。不同通道的配置见 [官方助理说明](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Assistant)。

### 1.2 微信小程序方式

优先使用官网或桌面“多端协同”给出的正式小程序入口，按页面完成账号验证。打开一项练习任务，核对标题、产物和能否继续对话；看不到某项资料、技能或连接器时，不把它当成全量同步已经完成。

小程序能做哪些操作，以当前账号实际显示为准；结果通知、手机续聊和 IM 助理遥控电脑分别验证，不因为能够打开小程序就假定通知与远程能力都已接通。

### 1.3 企业微信方式（团队场景）

企业微信接入先按 [官方企微助理指南](https://www.workbuddy.cn/docs/workbuddy/Wecom-Guide)创建并绑定智能机器人，再在其可见范围内使用。管理员和有创建权限的普通成员都有配置路径；购买 WorkBuddy 企业版不会自动替你完成机器人绑定，也不能保证企业微信里能用桌面的全部能力。

### 1.4 接通时卡住怎么办

```text
❌ 搜不到 WorkBuddy 公众号/小程序
   → 名字可能用全称或简称，多试几个关键词
   → 让已经用过的人把名片/链接推给你，直接点进去

❌ 授权后没反应
   → 检查登的是不是桌面同一个微信账号
   → 退出重新登，或重启微信

❌ 提示"账号未开通"
   → 你可能登的是不同的微信号，切回桌面的那个
   → 或企业账号没开通移动端权限，问管理员

❌ 企业微信里看不到 WorkBuddy
   → 公司没开通这个应用，问 IT
   → 或你没在可见范围内，让管理员加
```

## 第二步：跨端接力实战（15 分钟）

老金带你跑一个完整跨端任务，让你感受"桌面开、手机接"的顺畅。

### 2.1 桌面开任务

在桌面 App 里召唤办公写作专家，发一个会跑几分钟的任务：

```text
基于我的"个人工作资料库"，整理一份本周工作复盘：
- 完成了哪些事
- 没完成的事和原因
- 下周要优先处理的 3 件事
格式：Markdown，800 字以内。
```

发出去后，先到**头像 → 设置 → 通用**，把「允许锁屏运行」选成「**熄屏后继续运行**」，确认电脑接着电源、网络稳定。锁屏后用手机确认任务仍在继续，再离开电脑；需要演示时屏幕一直亮着，才选「保持屏幕常亮」。

### 2.2 路上手机查看

打开手机微信 WorkBuddy 小程序，进入任务列表，你会看到刚才那个任务正在跑（或已完成）。如果完成了，直接在手机上看产出；如果还在跑，等它完成会推送通知给你。

### 2.3 在手机上继续操作

看完产出后，你可以直接在小程序里继续提问：

```text
"刚才那份复盘里没完成的事，帮我细化一下'原因'部分，
我要拿这部分跟 leader 沟通调整下周计划。"
```

先确认打开的是刚才的同一任务，检查材料与已有产物，再继续追问。不要把能续聊理解成所有历史材料都必定完整进入这一轮上下文。

### 2.4 推送给同事

复盘改完后，用小程序的分享功能，把这份文档推给你的企业微信同事，或导出到腾讯文档（通过连接器）。

### 2.5 跨端接力的实际价值

```text
✅ 碎片时间利用（通勤、等候时手机处理）
✅ 不被设备束缚（出门也能继续工作）
✅ 即时响应（桌面跑完立刻手机收到，不用回电脑看）
✅ 协作顺畅（手机直接转给同事，不用导来导去）
```

## 第三步：远程触发实战（手机指令桌面干活）

这部分 WB-07 讲过基础，这里补完整场景。

### 3.1 典型场景：出差时让桌面跑复杂任务

你要出差三天，但手头有个需要桌面算力的复杂任务。你可以：

```text
出差途中，手机发指令：
"基于我的'客户资料库'，整理出 Top 10 客户的全年合作情况，
按合同金额排序，每家附上关键节点和未完成承诺。
跑完推到我的企业微信，我明天见客户用。"

桌面端 App（家里/公司电脑只要开着）接到任务开始执行：
- 检索知识库
- 召唤销售专家产出
- 通过连接器推送到你的企业微信

你晚上到酒店打开企业微信，结果已经在那等你了。
```

### 3.2 远程触发的注意点

```text
⚠️ 桌面 App 必须保持在线状态
   - 在头像 → 设置 → 通用，把"允许锁屏运行"设为"熄屏后继续运行"
   - 检查系统电源设置，别让电脑进入睡眠或关机；先锁屏测试一次再离开
   - 网络要稳（断网任务跑不了）
   - 重启电脑后 App 要能自动启动（设置开机自启）

⚠️ 远程指令要写清楚
   - 别发"看看我那个东西"，AI 不知道指啥
   - 写明任务、目标、输出（参考 WB-03 黄金提问模板）

⚠️ 大任务别远程触发
   - 跑 30 分钟以上的复杂任务，远程触发难监控
   - 大任务先在桌面跑，远程只用来触发轻量任务和查进度
```

## 第四步：微信群里用 WorkBuddy（团队协作）

### 4.1 群里 @ WorkBuddy

如果公司开了企业微信群集成，你可以在群里直接 @ WorkBuddy 让它处理任务：

把需要处理的方案正文或有权限的附件随本次请求发送，再 @ 已配置的机器人：

```text
@WorkBuddy 请只根据本次消息附带的虚构项目方案，
列出 3 个需要继续确认的风险点，每项指出对应原文。
资料没说的写“待确认”，先给草稿，不代表法律结论。
```

核对机器人实际收到的材料和回复。不默认它能读取 @ 之前的全部群聊，也不把机器人回复当成正式审查意见。

### 4.2 群协作的注意点

```text
⚠️ 群任务查看实际执行账号与用量记录，不按消息发送者推断固定扣费对象
⚠️ 把本次需处理的材料随请求发送，核对可见范围，不默认读取全部历史
⚠️ 涉及机密的话题别在群里让它处理（其他人能看到）
⚠️ 群里回复要简短（长回复刷屏），复杂任务让它私聊给你
```

### 4.3 团队任务分担

群里 @ WorkBuddy 还能做"团队分担"——比如有同事问了个问题，你让它回答，它帮你消化后你再回复同事。适合你不想直接答但又不好推脱的场景。

## 第五步：多端数据同步和冲突处理

### 5.1 逐项验证可见范围

先在手机打开桌面上的同一练习任务，核对标题、执行状态、已有产物与继续输入的入口。资料、应用、技能和连接器能否在该端使用，要按本账号实际显示检查；本地文件与设置不能因为同账号登录就推定已经上传。

例如，官方助理有自己的工作目录与执行记录，左侧菜单的自定义分组则保存在当前设备。你要确认的是本次任务用到的材料和结果能否继续访问，而不是记住一个“所有配置全同步”的保证。

### 5.2 同时操作时先看任务与文件

同一时间尽量只从一端修改同一文件。发现两边状态不一致，先保存已有结果，检查文件差异与各任务运行记录，再决定采用哪份修改；不把“最后保存覆盖”当成所有功能的冲突规则。

新任务是否并行或排队取决于入口与执行方式。普通任务可以有多项，远程助理的指令集中在其会话中；发送前确认当前任务状态，避免同一资源被重复处理。

### 5.3 离线与恢复

断网时先查看实际任务状态，保存已经生成的文件和结果。已经启动的某些本地进程可能继续，但这不能证明模型请求、远程指令和结果通知仍可正常执行。

网络恢复后，核对运行记录、产物和是否重复执行，再决定是否重试；同步耗时以当前记录为准，不承诺几秒内全部恢复。

## 第六步：多端使用的安全注意

老金这一步是为你好——多端便利也意味着风险面变大。

### 6.1 手机端的安全

```text
✅ 手机锁屏加密码（别让别人能直接打开你的微信用 WorkBuddy）
✅ 使用手机和微信实际提供的账号保护措施，不假定小程序必有独立加锁按钮
✅ 别在公共或他人手机登录 WorkBuddy 账号
✅ 手机丢失时先按微信/企业微信官方账号恢复流程处理，并在 WorkBuddy 助理设置解绑受影响通道；需要清理平台授权时到对应平台检查
```

### 6.2 公共网络的安全

```text
🚫 别在公共 WiFi（咖啡店、机场）触发敏感任务
🚫 别在公共网络下让它读敏感知识库
✅ 出差用流量或个人热点，更安全
```

### 6.3 企业版的多端管控

```text
- 由管理员核对移动端开放范围、机器人可使用成员和数据权限
- 离职或换岗时，检查账号、平台机器人与 WorkBuddy 助理绑定是否一并处理
- 是否提供强制桌面访问、远程清除等治理能力，按所购版本文档或合同确认，不作为已验证按钮
```

## 常见问题

**Q1：手机端要单独付费吗？**
不用。同一个账号所有端通用，积分也共享。

**Q2：手机端功能跟桌面一样全吗？**
不一样。手机端偏轻量交互（看、问、触发），桌面端是主力工作台（建知识库、配连接器、跑复杂任务）。复杂操作建议桌面，手机用来协同和移动场景。

**Q3：桌面没开，手机能触发任务吗？**
本章的远程助理控制电脑，需要电脑开机、联网并运行 WorkBuddy。若账号另有云端任务入口，按该入口官方说明确认执行位置和调度条件；不能仅因任务用了连接器或资料库，就推断电脑关闭后仍能执行。

**Q4：多端登录会冲突吗？**
先按本章 5.1 节确认两端使用的账号、任务和可见材料，再检查当前任务是否支持继续处理。同一份文件尽量只从一端修改；两边状态不一致时，保存已有结果并核对运行记录，不把登录成功当成全部数据已实时同步。

**Q5：手机端能用专家团吗？**
先查看当前手机入口是否提供对应专家团，或能否通过已绑定助理调用该能力；没有入口时在桌面开始，再验证手机能看到哪些结果。长文档与表格可在桌面核对，通知通道单独配置。

**Q6：企业微信里的 WorkBuddy 跟个人的 WorkBuddy 是同一个吗？**
企业微信只是接入通道，最终使用哪个 WorkBuddy 账号与任务范围，取决于绑定和企业配置。先查看执行账号、机器人可使用成员及任务记录，不从消息平台名称直接推断一定是企业或个人数据空间。

**Q7：手机端消耗积分跟桌面一样吗？**
一样的。同一个账号同一种任务，不分端按积分扣。

**Q8：能不能让 WorkBuddy 主动给我手机推消息（不靠我触发）？**
能。这就是自动化推送（看 WB-07）。配好后到点自动推，不用你触发。
