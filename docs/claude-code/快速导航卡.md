## 🔑 关键术语速查


| 术语 | 通俗解释 | 类比 |
|------|----------|------|
| **Claude Code** | AI编程助手命令行工具 | 24小时在线的高级程序员 |
| **MCP** | 连接外部工具的协议 | USB接口标准 |
| **Hook** | 事件触发的处理器，可运行命令、调用模型或外部工具 | 汽车传感器（自动触发） |
| **Skill** | 包含指令和可选脚本的可复用技能目录 | 重复任务的操作说明 |
| **Plugin** | 打包分发 Skills、agents、hooks、MCP 等组件 | 一套可安装的扩展包 |
| **Remote Control** | 从手机或浏览器继续本地会话 | 手机上的本地会话遥控器 |
| **Channels** | 把 Telegram/Discord/Webhook 事件推入当前会话 | 给 Claude 装消息总线 |
| **API Key** | API 路径的一种认证凭据；订阅和 Console 浏览器登录不一定需要 | 指定服务的访问凭据 |
| **Agent Teams** | 实验性的多代理团队协作 | 项目组分工合作（需显式开启） |
| **Sandbox** | 在 OS 层限制 shell 命令及子进程的文件和网络访问 | 命令执行的安全围栏 |
| **HTTP Hook** | 事件触发远程Webhook | 远程报警器 |
| **--dangerously-skip-permissions** | 跳过权限询问（危险！） | 保姆不问直接干 |

这里的 OS 沙箱需要启用，并且只约束 shell 命令；文件工具、MCP 和 Hook 要分别检查权限与来源。原生 Windows 的平台限制见下方 Q5。

## ⚠️ 重要风险速查

| 功能 | 风险机制 | 建议 |
|------|------|---------|
| **--dangerously-skip-permissions** | 跳过权限确认后，AI 可能直接读写文件、运行命令 | 新手禁用；重要项目禁用 |
| **Hooks** | 可运行脚本、发送请求或调用工具，配置不当可能改坏文件或泄露信息 | 核对配置、脚本与服务来源，先在测试仓库验证 |
| **MCP HTTP** | ⚠️ 远程连接需要安全配置 | 勿暴露敏感信息 |

## 🆘 常见问题快速解答

### Q1：完全零基础能学吗？

**A**：能学，但要分目标：
- **只想理解和体验 AI Coding**：先完成 01 安装，再做 02 的两文件小 Bug 练习，观察提问、修改和检查之间的关系。
- **想独立改真实项目代码**：建议补命令行基础和一门编程语言基础，再进入 02 基础使用和 10 综合实战。
- **企业 / 高校培训**：可以把本卡当课程地图，先讲概念、权限、安全，再进入实操。

### Q2：第一次要读多久？

**A**：环境已可用时，先留 20–30 分钟做完一个小练习；安装、登录和排障时间另计。表中的学时适合规划阅读，实际掌握程度要看你能否换一个任务独立完成。

### Q3：必须按顺序学吗？

**A**：
- 尚未安装：先完成 01 中适合本机的一条路径。
- 已安装：先做 02 的小任务；04–08 按实际需要选学。

### Q4：遇到问题怎么办？

**A**：
1. Ctrl+F搜索教程内的FAQ
2. 查看故障排查章节
3. 查官方文档
4. 学习群提问

### Q5：Windows/Mac都能学吗？

**A**：安装和基础使用覆盖 Windows、macOS 与 Linux。具体功能和示例有平台限制：iMessage 仅支持 macOS，原生 Windows 不支持 OS sandbox，Bash 脚本需在对应 shell 或 WSL 中运行。跟练前先看代码块注明的环境。
